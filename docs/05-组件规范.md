# 05 组件规范

> 全站组件清单与 API 定义。新建组件前先查此表；新增组件需先补充本文档。
> 分层：`layout/`（页面壳）→ `ui/`（无业务语义基础件）→ `features/`（业务组件）。

## 0. 全局约定

- 全部使用 `<script setup>`；props 声明 `type` + `default`（必填项不设默认）
- 数据单向流：父组件传 props，子组件 `emit` 事件；禁止组件内直接改 props
- 样式 `scoped` + 设计令牌；禁止魔法值（颜色/间距/圆角必须走 `--` 变量）
- 组件 ≤ 200 行；超出拆分。重复出现 ≥ 2 次的 UI 提取为组件
- 所有交互元素带 `aria-label` 或可见文本；点击目标 ≥ 44px

## 1. layout/（页面壳）

### AppHeader

| 项 | 定义 |
| --- | --- |
| 作用 | 全站顶部导航：品牌 + 导航 + 移动抽屉 |
| Props | 无（导航配置从路由表派生：路由 meta.nav === true 的项） |
| Events | 无 |
| 实现要点 | 滚动 40px 后加 1px 底部边框（可选）；移动端抽屉：菜单按钮 `aria-expanded`、遮罩、Esc 关闭、关闭后焦点回按钮；固定头部（sticky top-0，bg 半透明 0.9 + backdrop-blur） |

### AppFooter

| 项 | 定义 |
| --- | --- |
| 作用 | 页脚：品牌 + 版权（自动年份）+ 主要外链 |
| Props | 无 |
| 实现要点 | 上方 1px 细线；copyright 用 `new Date().getFullYear()`；外链用 `ExternalLink` |

### PageTransition

| 项 | 定义 |
| --- | --- |
| 作用 | 包 `<router-view>`，页面切换淡入 |
| Props | 无 |
| 实现要点 | `<Transition mode="out-in" name="page">`，150ms fade + 8px 上移；CSS 在 base.css 全局类（`.page-enter-active` 等） |

### PageHeader

| 项 | 定义 |
| --- | --- |
| 作用 | 列表页页头：标题 + 描述 + 可选计数 |
| Props | `title: string`（必填）、`description?: string`、`count?: number`（渲染 `共 N 项`）、`grid?: boolean`（true 显示网格纹理背景） |
| 实现要点 | h1 用 `--text-h1`；description 用 secondary 色；底部 48px 间距 |

### SkipLink

| 项 | 定义 |
| --- | --- |
| 作用 | 无障碍跳转：键盘首 Tab 聚焦时显示"跳到主要内容" |
| Props | 无 |
| 实现要点 | 视觉隐藏，聚焦显示；目标 `#main`（App.vue 中 `<main id="main">`） |

## 2. ui/（基础件）

### StatusBadge

| 项 | 定义 |
| --- | --- |
| 作用 | 项目/Lab 状态徽章 |
| Props | `status: 'development' \| 'completed' \| 'archived' \| 'experiment'` |
| 映射 | development→开发中 / completed→已完成 / archived→已归档 / experiment→实验 |
| 实现要点 | 色板见 `03-设计系统` §2.3；圆角 4；13px；`aria-label="状态：开发中"` |

### Tag

| 项 | 定义 |
| --- | --- |
| 作用 | 技术/主题标签 |
| Props | `label: string`（必填）、`active?: boolean`、`clickable?: boolean` |
| Events | `click`（仅 clickable 时触发） |
| 实现要点 | 文本标签优先展示完整名，超长省略（title 提示）；active 态 accent-soft 底 + accent 边框 |

### SectionTitle

| 项 | 定义 |
| --- | --- |
| 作用 | 区块标题（首页与列表页使用） |
| Props | `title: string`（必填）、`index?: string`（如 "01" 序号）、`to?: string`（"查看全部"链接） |
| 实现要点 | 序号用 mono + tertiary 色；标题左侧 4px accent 竖线（可选）；右侧 `to` 渲染小链接 |

### Card

| 项 | 定义 |
| --- | --- |
| 作用 | 通用卡片容器（封装边框/圆角/hover 抬升） |
| Props | `as?: 'div' \| 'a' \| 'router-link'`（默认 div）、`href?: string`、`to?: string`、`hoverable?: boolean`（默认 true） |
| Slots | `default` |
| 实现要点 | hover 抬升样式由 Card 统一实现，业务组件不重复写 |

### Icon

| 项 | 定义 |
| --- | --- |
| 作用 | 内联 SVG 图标 |
| Props | `name: 'github' \| 'mail' \| 'arrow-left' \| 'arrow-right' \| 'external' \| 'menu' \| 'close' \| 'calendar' \| 'code'`、`size?: number`（默认 20）、`label?: string`（传入则加 aria-label，缺省 aria-hidden） |
| 实现要点 | 统一 1.5px 线宽；`<svg>` 直接内联映射表，不引图标库 |

### ExternalLink

| 项 | 定义 |
| --- | --- |
| 作用 | 外链统一封装 |
| Props | `href: string`（必填）、`icon?: boolean`（默认 true，尾部外链图标） |
| Slots | `default`（链接文本） |
| 实现要点 | `target="_blank" rel="noopener noreferrer"`；hover 下划线 |

### EmptyState

| 项 | 定义 |
| --- | --- |
| 作用 | 空结果占位（过滤无结果、数据为空） |
| Props | `message?: string`（默认"这里暂时是空的"）、`actionLabel?: string` |
| Events | `action`（清除筛选按钮） |
| 实现要点 | 居中、secondary 文字、留白充足 |

### ArticleContent

| 项 | 定义 |
| --- | --- |
| 作用 | Markdown 渲染容器（项目详情/笔记详情共用） |
| Props | `html: string`（必填，markdown-it 输出） |
| Slots | `#extra`（**预留**，v2.0 动态数据区用）：正文之后的插槽，v1 不渲染 |
| 实现要点 | `v-html` + `markdown.css` 作用域类（`.article`）；`##` 标题自动生成 id（`<slug>-<n>` 序号，供锚点，见 `14` §5.2）；代码块外层加语言角标（可选 v1）；图片懒加载 + 圆角 |

## 3. features/（业务组件）

### HeroSection

| 项 | 定义 |
| --- | --- |
| 作用 | 首页首屏 |
| Props | `site: object`（site.json 解析结果） |
| 子件 | 姓名（display 字体）、role、tagline（≤2 行）、CTA（primary: View Projects → `/projects`；ghost: GitHub → 外链）、TagRotator |
| 实现要点 | 网格纹理背景（`03-设计系统` §5）；min-height 55vh 垂直居中；移动端字号降档 |

### TagRotator

| 项 | 定义 |
| --- | --- |
| 作用 | 标签轮换显示 |
| Props | `tags: string[]`（必填）、`interval?: number`（默认 500ms） |
| 实现要点 | `v-if` + `<Transition>` 淡入淡出 200ms；`prefers-reduced-motion` 下静态显示第一项；无 tags 时渲染空 |

### ProjectCard

| 项 | 定义 |
| --- | --- |
| 作用 | 项目档案卡片（列表页 + 首页精选） |
| Props | `project: object`（管线输出的 meta）、`featured?: boolean`（true 时大卡片布局，含"精选"标识） |
| 布局 | 标题 / subtitle / StatusBadge 一行 → summary → tech 标签组 → 底部 demo/github 链接 |
| 实现要点 | 整卡可点击跳详情（`RouterLink` 包裹），内部链接 stop 冒泡；featured 变体：2 列布局或加大内距 |

### NoteCard

| 项 | 定义 |
| --- | --- |
| 作用 | 笔记列表行 |
| Props | `note: object`（管线输出） |
| 布局 | 日期（mono 13px tertiary）| 标题 + summary + tags 一行 |
| 实现要点 | 整行可点击跳 `/notes/:slug` |

### TimelineItem

| 项 | 定义 |
| --- | --- |
| 作用 | 时间线条目 |
| Props | `item: object`（timeline.json 条目） |
| 布局 | 左列：月份（mono）；中列：节点圆点 + 竖线；右列：标题 + 类型徽章 |
| 实现要点 | 圆点按 type 着色（project=accent / learning=green / note=purple / milestone=text）；竖线用 `::before` 连续绘制 |

### LabItem

| 项 | 定义 |
| --- | --- |
| 作用 | Lab 卡片 |
| Props | `item: object`（lab.json 条目） |
| 布局 | 标题 + StatusBadge → description → 日期 + 可选链接 |

### FilterBar

| 项 | 定义 |
| --- | --- |
| 作用 | 列表页筛选（状态 / 技术栈） |
| Props | `statusOptions: string[]`、`techOptions: string[]`、`modelValue: { status?: string, tech?: string[] }` |
| Events | `update:modelValue` |
| 实现要点 | 状态为单选标签组（含"全部"）；技术栈为多选标签组（OR 逻辑）；变化即写 URL query（组件不直接改路由，由页面监听 modelValue 同步） |

## 4. 组件依赖图（方向只向下）

```
App
├── SkipLink
├── AppHeader
├── PageTransition → RouterView → pages
│   └── pages 组合 features + ui 组件
└── AppFooter
pages 示例（Home）：
  Home → HeroSection(TagRotator, ExternalLink)
       → SectionTitle
       → ProjectCard ×3 (Card, StatusBadge, Tag, ExternalLink)
       → NoteCard ×3
```

规则：

- features 之间不互相引用（页面层组合）
- ui 组件不 import features 组件
- 业务文案只出现在 content 层，组件内不写死文案
