# 03 设计系统

> 视觉方向：**暖白纸张感 · 极简 · 细线 · 克制动效**（设计师作品集气质，禁止科技蓝 / 代码雨 / 赛博朋克）。
> 本文档是唯一视觉事实来源。`tokens.css` 必须与本文档一致；样式改动需先改这里。

## 1. 品牌与语气

- 品牌：Yuer Studio（文字标识，不设计复杂 logo）
- 语气：克制、直接、有温度。标题陈述句/名词短语，正文第一人称，不喊口号
- 中英混排：正文中文为主，技术术语保留英文；英文单词与中文间留空格

### 2.4 代码高亮色板（hljs 亮色主题）

代码块为**浅色纸张风**（F04 明确非暗色终端风），hljs 默认主题不可用，需在 `markdown.css` 中覆盖。色板（全部取自上表与中性色，控制在 6 色以内，克制）：

| `.hljs-string` / `.hljs-attr` / `.hljs-attribute` | 字符串/属性 | `#336B43`（墨绿，同 completed） |
| `.hljs-title` / `.hljs-title.function_` | 函数名 | `#5A4B8A`（深紫，同 experiment） |
| `.hljs-comment` / `.hljs-quote` | 注释 | `#6F6F6A`（灰，同 archived） |
| `.hljs-number` / `.hljs-literal` / `.hljs-built_in` | 数字/内建 | `#1F1F1D`（正文色） |
| `.hljs-variable` / `.hljs-params` / `.hljs-name` | 变量/参数 | 继承正文色，`font-style: italic` 区分 |

- 代码块底色：`--color-surface-muted`（#F3F2EC 次级块，正是为代码块/日期块定义）；边框 `--color-border`

## 5. 布局与网格

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| `--container` | 960px | 内容容器最大宽度 |
| `--container-narrow` | 720px | 正文阅读宽度（详情页） |
| `--bp-sm` | 640px | 移动端断点 |
| `--bp-md` | 1024px | 平板断点 |
| `--grid-gap` | 24px | 卡片网格间距 |

- 容器左右 padding 16px（移动）→ 32px（桌面）
- 卡片网格：桌面 2 列（`repeat(auto-fit, minmax(320px, 1fr))`），移动单列
- 列表页垂直节奏：PageHeader 下 48px，区块之间 48px
- **断点令牌（`--bp-*`）仅作文档标注**：CSS 变量不能用于媒体查询，实际媒体查询一律写死 `640px` / `1024px` 字面量（见 `14-技术架构设计` §5.10）

### 背景纹理（仅 Hero 区）

```

  linear-gradient(var(--color-border) 1px, transparent 1px),
  linear-gradient(90deg, var(--color-border) 1px, transparent 1px);
```

## 6. 交互状态

| 元素 | 默认 | hover | focus-visible | active |
| --- | --- | --- | --- | --- |
| 链接（正文） | accent、无下划线 | 下划线 + accent-hover | 全局焦点样式 | — |
| 卡片 | 白底 + 细边框 + shadow-card | 边框变 border-strong + 轻微抬升（translateY -2px）+ shadow-card-hover | 焦点样式 | 按下微缩 |
| 按钮（primary） | accent 底 + 白字 | accent-hover | 焦点样式 | 下压 |
| 按钮（ghost） | 透明 + accent 文字 + 细边框 | accent-soft 底 | 焦点样式 | 下压 |
| 标签（可点） | 灰底 | 边框加深 | 焦点样式 | 选中态 accent-soft 底 |
| 徽章 | 状态色底 | 不可交互 | — | — |

全局焦点样式：

```css
:focus-visible {
  outline: 2px solid var(--color-accent);
  outline-offset: 2px;
}
```

过渡统一 `var(--dur-fast)` 150ms / `var(--ease-standard)`。

## 7. 动效

### 7.1 令牌

| 令牌 | 值 |
| --- | --- |
| `--dur-fast` | 150ms |
| `--dur-base` | 250ms |
| `--dur-slow` | 400ms |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` |
| `--ease-out` | `cubic-bezier(0, 0, 0.2, 1)` |

### 7.2 动效清单（全站仅此几处）

| 位置 | 效果 | 参数 |
| --- | --- | --- |
| 页面切换 | 淡入上移 | 150ms，位移 8px，`--ease-standard` |
| 标签轮换 | 淡入淡出 | 停留 500ms，切换 200ms |
| 卡片 hover | 抬升 + 阴影加深 | 150ms |
| 滚动入场 | 淡入上移（仅区块标题与卡片组） | 300ms，位移 16px，IntersectionObserver 一次触发，组内 stagger 60ms |
| 抽屉开关 | 滑入 + 遮罩淡入 | 250ms |
| 焦点指示 | 出现 outline | 无动画 |

### 7.3 克制原则

- 滚动入场**只对首个视口以下的内容**生效，且只触发一次
- 不做视差、不做滚动驱动动画、不做循环动画（标签轮换是唯一循环）
- 尊重 `prefers-reduced-motion`：

```css
@media (prefers-reduced-motion: reduce) {
  * { transition-duration: 0.01ms !important; animation-duration: 0.01ms !important; }
}
```

标签轮换、滚动入场在 reduced-motion 下退化为静态显示。

## 8. 图标

- 线宽 1.5px，圆角端点（stroke-linecap: round）
- 尺寸：16（标签内）/ 20（列表项）/ 24（CTA 按钮）
- v1 图标集（内联 SVG 组件）：`github` `mail` `arrow-left` `arrow-right` `external` `menu` `close` `calendar` `code`
- 图标按钮必须带 `aria-label`；装饰性图标 `aria-hidden="true"`

## 9. 组件样式基调

- 卡片：白底、圆角 8、细边框、极淡阴影；hover 抬升
- 徽章：圆角 4、状态色底、13px、padding 2px 8px
- 技术标签：圆角 4、灰底（`--color-surface-muted`）、13px mono 字体点缀
- 日期：13px mono、text-tertiary 色（装饰性）
- 分隔线：`--color-border` 1px

## 10. 暗色模式

v1 明确不做。若未来评估，需整体重新设计（纸张感语义在暗色下不成立），不采用"自动反转"方案。
