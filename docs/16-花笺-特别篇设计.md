# 16 花笺 — 特别篇视觉与信息架构

> 名称：**花笺**（不是「纸张主题」，是「Yuer 世界被印在一张会被风翻动的笺上」）。
> 与 `15-演进路线` 的关系：`/room` 仍是书房核心；花笺是**第二层视觉语言 + 漫游入口**，不替换 SEO 列表层。
> 原则：原世界 90%，纸感 10%。花 = 入口，笺 = 容器，书房 = 停留。

## 1. 一句话

花园负责「遇见」，书房负责「停留」，笺后的世界负责「进入」。

## 2. 结构

```text
Lab → 花笺
        │
     花庭（风、落花、留白）
        │  花 = 被风翻起的一角
        ├→ 作品  → /projects
        ├→ 诗境  → 笔记/短文（可暂并 Notes）
        ├→ 学习  → /notes /lab
        ├→ 实验  → /lab
        ├→ 关于  → /about /contact
        └→ 书房  → 现有 3D /room 或花笺内嵌
                      桌=项目  架=学习  桌上书=诗境
                      窗=世界外景  门=回花庭
```

内容仍读 `src/content/*`，只换「如何到达」。

## 3. 视觉关键词

**现代 × 纸感 × 花 × 空气 × 留白 × 私人感**

| 维度 | 规则 |
|------|------|
| 色彩 | 继承现站：米白 `#fafaf8`、墨 `#1f1f1d`、陶土 `#b05c3a`；不另建彩虹 |
| 纸 | 纤维/微颗粒/受光，**不是**满屏牛皮纸滤镜 |
| 墨 | 正文可略非纯黑；标题边缘极轻柔化 |
| 花 | 纸/绢质感，非塑料；红仅极少量 |
| 光 | 自然光、台灯、窗光；禁霓虹、禁 AI 渐变 |
| 字 | 沿用现站；仅标题/诗行稍增文学感 |
| 名 | 「花笺」可一闪而过，不挂大 Hero 标题 |

## 4. 有纸感 / 无纸感

**要有：** 花庭底、转场、书与笔记、世界入口边缘、书房纸制品  

**禁止：** 3D 地板、城市夜景、屏幕/代码、建筑、皮肤、全站纸滤镜、玻璃拟态、HUD、卡片瀑布、女孩头像墙

## 5. 花瓣交互（门，不是按钮）

1. 落下：速度/摆动/翻转各异，有「风」
2. 接近：轻微偏转 + 细空气扰动
3. 停留：极淡名字（如「作品」「诗境」）
4. 点击：风卷起 + 转场 500–900ms  
   花园→世界：像**翻页**；书房书→世界：书页展开成场景

禁止：一瓣对应 GitHub/Contact 等琐碎功能。

## 6. 世界入口（5–7，第一版）

| 世界 | 花/入口感 | 内容映射 | 用户感受 |
|------|-----------|----------|----------|
| 作品 | 较快的一朵 | Flagship+product → `/projects` | 有人在做真东西 |
| 诗境 | 白梅 | 笔记精选 / 短文 | 安静、纸与字 |
| 学习 | 落在书上的花 | `/notes` `/lab` | 认真在学 |
| 实验 | 被吹偏的花 | lab | 允许未完成 |
| 关于 | 很慢下落的一朵 | about/contact/github | 人在但不吵 |
| 书房 | 院门/灯 | 3D room | 停留、沉淀 |

## 7. 书房（继承 GLB，不重做）

- 桌面：纸、半开的书、笔、杯、灯（不塞 RGB 电竞）
- 书架：书 + 文件夹/薄笔记
- 墙：一张夹起的纸即可，不挂诗词墙
- 窗：窗外 = 2D 世界；偶有花瓣飘入（与花庭同一宇宙）
- 出口：门/回望 → 回花庭；旁路始终有「列表浏览」
- 人：缺席但有痕迹（拉开的椅、翻开的书、亮着的灯）

时间/雨声/桌面笔记轮换：**Phase 5**，访问记忆可后做。

## 8. 技术分层

```text
L1 现站     路由 / SEO / 列表 / 无障碍
L2 花笺     花瓣系统 / 转场 / 场景状态（Canvas 或 SVG，非 WebGL）
L3 书房     现有 Three + GLB；手机可退化 2.5D 静图+热区
```

性能：花庭不用 Three；书房 DPR≤1.25、已关阴影；世界场景静态图+微动。

## 10. 阶段

| Phase | 做什么 | 退出 |
|-------|--------|------|
| 0 | 本表 + 每世界一句「感受」 | 定稿 |
| 1 | 花庭骨架→1 世界→书房门闭环 | Lab 能走完一圈 |
| 2 | 花瓣风物理 + 翻页转场 | 愿意多停 10 秒 |
| 3 | 书房桌/架/书/窗/灯 | 进现有内容 |
| 4 | 其余世界模板化 | 5–7 口全通 |
| 5 | 时间/雨/音（可选） | 打磨 |

## 11. 禁区（执行红线）

巨大 Hero、卡片瀑布、玻璃拟态、AI 渐变、满屏粒子、科技蓝、霓虹、复杂 HUD、满屏可点、女孩头像墙、传统三件套导航占满首屏、为炫技把交互做满。

## 12. 与 AI 生图/写码的约束

- Prompt 继承：米白纸 + 陶土 + 墨；禁霓虹/赛博/过度锐利
- 不给每张图统一「古风纸滤镜」
- 界面文案少而准；不解释「这是花笺主题空间」
- 实现顺序：先闭环，再精修美术
