# 06 页面布局规范

> 每个页面的线框、内容顺序、响应式行为、空状态与 SEO 元信息。
> 视觉数值（字号/间距/颜色）一律引用 `03-设计系统`，不在此重复。

```
┌──────────────────────────────────────┐
│ AppHeader                            │

│                                      │
│   Yuer                        ← display 40px

├──────────────────────────────────────┤
│  01 Featured Projects       查看全部 →│ ← SectionTitle
│  ┌─────────────┐ ┌─────────────┐    │
│  │ ProjectCard │ │ ProjectCard │    │ ← featured 前 3，grid 2 列
```

- 响应式：Hero 文字移动端降档；项目网格移动端单列

- SEO：title 按 `02-信息架构` §2 路由表规则（`site.brand · tagline[0]`）；description 用 site.bio；OG 齐全

```
┌──────────────────────────────────────┐
```

```
│                                      │
│ FilterBar：                           │

│                                      │

│ ┌───────────┐ ┌───────────┐          │
│ │ProjectCard│ │ProjectCard│  …       │

│                                      │
```

- 卡片 hover 抬升；点击整卡进详情

---

## 通用规则

1. 所有列表页 PageHeader 下间距 48px；区块间距 48px
2. 详情页正文窄栏 720px；卡片容器 960px
3. 移动端：所有水平排列（标签组、日期行）允许换行，标签间距 8px
4. 每页必须有唯一 `h1`（PageHeader 或详情页标题）
