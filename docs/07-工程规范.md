# 07 工程规范

> 代码层面的硬性规范：目录、命名、风格、Git、质量门、性能、a11y、部署。

## 1. 技术选型与理由

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | Vue 3（`<script setup>` 组合式 API） | 生态成熟、TS 可选（v1 用 JS）、与后续 AI 能力集成顺畅 |
| 构建 | Vite | 快、`import.meta.glob` 原生支持内容管线 |
| 路由 | vue-router 4 | 标准方案，懒加载 + meta + scrollBehavior |
| Markdown | markdown-it + highlight.js | 体积小、样式可控；v1.5 可替换 SSG；渲染整体移入详情页懒加载 chunk（`14-技术架构设计` §5.2） |
| frontmatter | 手写轻量解析器（约 50 行） | 受控子集 + 校验脚本兜底；省掉 gray-matter/js-yaml 约 15KB gzip，保住首屏预算（`14-技术架构设计` §5.1） |
| 样式 | 原生 CSS + 设计令牌 | 视觉完全可控，避免"组件库脸" |
| 托管 | GitHub Pages + Actions | 免费、静态、自动部署 |

备选记录：Astro（内容站更自然）作 v2 候选；Element Plus / Tailwind 明确排除（会破坏设计系统一致性）。

## 3. 命名规范

| 对象 | 规范 | 示例 |
| --- | --- | --- |
| 组件文件 / 组件名 | PascalCase 多词 | `ProjectCard.vue` |
| 页面文件 | PascalCase | `Projects.vue` |
| 其他文件 / 目录 | kebab-case | `validate-content.mjs` |
| CSS 类 | kebab-case + BEM（仅业务组件内） | `.project-card__title` |
| CSS 变量 | `--<域>-<名>` | `--color-accent`、`--space-6` |
| JS 常量 | SCREAMING_SNAKE | `PROJECT_STATUS` |
| composable | `use` 前缀 | `useScrollReveal.js` |
| 路由路径 | kebab-case | `/projects/evocode` |
| 提交信息 | Conventional Commits | `feat(projects): add filter` |

## 4. 代码风格

- `<script setup>`；`ref`/`computed` 优先；逻辑拆 composable（> 80 行）
- props 用对象语法声明类型与默认值；必填不设默认
- 模板：组件标签自闭合；不写内联事件表达式逻辑（仅调用方法）
- 样式：组件内 `scoped`；全局样式只放三个 css 文件；禁止 `!important`（极少数除外需注释）
- 数据获取不写在组件内联代码中：一律走 `utils/content.js` 导出
- Prettier：`singleQuote: true`、`semi: false`、`printWidth: 100`、`trailingComma: 'es5'`
- ESLint：`eslint-plugin-vue`（vue3-recommended）+ JS 基础规则；`npm run lint` 零警告通过

## 5. Git 与分支

- 主分支 `main`；`feature/*` 分支开发，完成合并
- 提交类型表：`feat` 功能 / `fix` 修复 / `docs` 文档与内容 / `style` 样式 / `refactor` 重构 / `perf` 性能 / `test` / `chore` 构建与工具 / `ci` 流水线
- message 格式：`<type>(<scope>): <subject>`，subject 中文简述，≤ 50 字符
- 内容变更同样走 docs 类型（如 `docs(projects): add evocode`）
- 提交前必须通过：`npm run validate` + `npm run lint` + `npm run build`
- 禁止：提交 `node_modules/`、`dist/`、密钥、`*.env`

## 7. 性能预算

| 指标 | 预算 |
| --- | --- |
| 首页 LCP | ≤ 1.5s（Lighthouse 移动模拟 4G） |
| CLS | ≤ 0.1 |
| 首屏 JS | ≤ 150KB gzip（路由懒加载分块） |
| 图片 | 单图 ≤ 300KB；首屏外懒加载；显式宽高 |
| 字体 | 零外部字体请求（系统字体栈） |

违例场景处理：任何引入（依赖/图片/动画库）需先评估以上预算，超预算需评审。

## 8. 无障碍（a11y）清单

- 语义：`header/nav/main/footer` landmark；每页唯一 `h1`；列表用 `ul/li`
- 键盘：全功能可键盘操作；`:focus-visible` 可见焦点（全局样式）
- 对比度：正文 ≥ 4.5:1（`03-设计系统` 色板已达标，新增颜色需验算）
- 标签：图标按钮 `aria-label`；装饰图标 `aria-hidden`；图片 alt 必填
- 动效：`prefers-reduced-motion` 全局降级
- 导航：SkipLink；抽屉 `aria-expanded`、Esc 关闭、焦点管理
- 目标尺寸：可点元素 ≥ 44px

## 9. 部署规范

### 9.1 GitHub Pages 配置

- 仓库：`<user>/<repo>`（如 `yuer/portfolio`）
- `vite.config.js`：`base: '/<repo>/'`（自定义域名时改 `'/'`）
- Actions 工作流（`.github/workflows/deploy.yml`）要点：

```yaml
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20, cache: npm }
      - run: npm ci
      - run: npm run validate
      - run: npm run lint
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with: { path: dist }
  deploy:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/deploy-pages@v4
```

### 9.2 深链兜底

构建后把 `index.html` 复制为 `dist/404.html`（package.json script：`"postbuild": "node scripts/copy-404.mjs"`）。

### 9.3 自定义域名（后续）

- `public/CNAME` 写入域名；DNS 加 CNAME 记录
- `base` 改 `'/'`；站长工具提交站点地图（v1.5 生成 sitemap.xml）

## 10. 依赖策略

- 生产依赖仅：`vue`、`vue-router`、`markdown-it`、`highlight.js`
- 开发依赖：`vite`、`@vitejs/plugin-vue`、`eslint`、`eslint-plugin-vue`、`prettier`
- 锁定版本（`package-lock.json` 提交）；大版本升级单独 commit

## 11. npm scripts（统一约定）

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "postbuild": "node scripts/copy-404.mjs",
    "validate": "node scripts/validate-content.mjs",
    "lint": "eslint src --ext .js,.vue",
    "format": "prettier --write src scripts",
    "check": "npm run validate && npm run lint && npm run build"
  }
}
```

- `npm run check` 为全量质量门，提交/发布前必跑
- 新增脚本需先在本文档登记（保持可预期）

## 12. 编辑器与工具

- Node 版本：20 LTS+（`.nvmrc` / `engines` 声明）
- `.editorconfig`：`charset=utf-8`、`indent=2 spaces`、`insert_final_newline=true`、`end_of_line=lf`
- 推荐 VSCode 插件：Vue Language Features (Volar)、ESLint、Prettier
- 保存时自动 format（Prettier）+ lint 修复
- 不用 any 插件生成代码（组件一律手写，保证一致性）

## 13. SEO 技术细节（v1 落地项）

- `index.html`：`lang="zh-CN"`、title/description、theme-color `#FAFAF8`、favicon、OG 标签
- 首页加 JSON-LD（`Person` 结构）：name、url、sameAs（GitHub）、jobTitle —— 静态写在 index.html（`14-技术架构设计` §5.7 已定）
- `robots.txt`：允许全部（`User-agent: * / Allow: /`），放 `public/`
- `sitemap.xml`：v1.5 生成（内容路由数量确定后脚本产出），v1 不手写
- 详情页 meta description 用 frontmatter `summary`；列表页用固定站点描述

## 14. 打印样式（低成本加分项）

- `base.css` 已含 `@media print` 基线（隐藏 header/footer/nav、窄栏取消）
- About / 项目详情页打印可输出接近简历/作品集的纸质文档，方便面试场景
- 验收：任意详情页 Ctrl+P 预览无异常（不追求完美，但不破版）
