## 第1章 编译概述

| 知识点 | 核心 |
|--------|------|
| 编译过程 | 词法分析→语法分析→语义分析→中间代码生成→代码优化→目标代码生成 |

## 第2章 文法与语言

| 知识点 | 核心 |
|--------|------|
| 文法四元组 | G = (Vₙ, Vₜ, P, S) |
| 终结符 | Vₜ，不能再分解的符号 |
| 非终结符 | Vₙ，可以继续推导的符号 |
| 产生式 | P，形如 α→β 的规则 |
| 句型 | 从S出发推导出的任意符号串 |
| 句子 | 不含非终结符的句型 |
| 语言 | 所有句子的集合 |

**文法分类（Chomsky层次）：**

| 类型 | 名称 | 产生式限制 | 识别器 |
|------|------|------------|--------|
| 0型 | 无限制文法 | α→β（α至少含一个非终结符） | 图灵机 |
| 1型 | 上下文有关文法 | αAβ→αγβ | 线性有界自动机 |
| 2型 | 上下文无关文法 | A→β（A为非终结符） | 下推自动机 |
| 3型 | 正规文法 | A→aB 或 A→a | 有限自动机 |

## 第3章 词法分析

| 知识点 | 核心 |
|--------|------|
| 正规式 | 表示正规集：`|`（或）、`·`（连接）、`*`（闭包） |
| DFA | 确定有限自动机，每状态每输入只有一个转移 |
| NFA | 非确定有限自动机，可有ε转移 |
| DFA最小化 | 等价类划分法（梅勒算法） |

## 第4章 语法分析（自上而下）

| 知识点 | 核心 |
|--------|------|
| LL(1)文法 | 自上而下分析，1个 lookahead 符号 |
| FIRST集 | 能推导出的终结符首符号集合 |
| FOLLOW集 | 非终结符后可能跟随的终结符集合 |
| 消除左递归 | A→Aα|β → A→βA', A'→αA'|ε |
| 提取左因子 | A→αβ₁|αβ₂ → A→αA', A'→β₁|β₂ |

---

## 第5章 语法分析（自下而上）

| 知识点 | 核心 |
|--------|------|
| 规范归约 | 最右推导的逆过程 |
| LR(0) | 自下而上分析，0个 lookahead |
| SLR(1) | 对LR(0)的改进，用FOLLOW集消冲突 |
| LR(1) | 1个 lookahead，更精确 |
| LALR(1) | LR(1)的合并状态版本 |

**LR分析表构造：**
- **项目**：产生式中加圆点表示分析进度
- **移进**：圆点后是终结符，移入栈
- **归约**：圆点在产生式末尾，归约
- **接受**：S'→S·
- **冲突**：移进-归约冲突、归约-归约冲突

## 第6-8章 语义分析·中间代码·优化

| 知识点 | 核心 |
|--------|------|
| 语义分析 | 检查类型一致性、作用域、参数匹配 |
| 三地址码 | 最多含三个地址的指令：`x = y op z` |
| 四元式 | (op, arg1, arg2, result) |
| 局部优化 | 常量传播、死代码消除、公共子表达式 |
| 循环优化 | 强度削弱、归纳变量删除、循环展开 |

## 核心对比速查表

| 编号 | A | vs | B | 一句话 |
|------|---|----|---|--------|
| 1 | DFA | NFA | 确定 vs 非确定，NFA可有ε转移 |
| 2 | 自上而下 | 自下而上 | 从开始符号推导 vs 从句型归约 |
| 3 | LL(1) | LR(1) | 从左到右扫描，1个 lookahead |
| 4 | 编译 | 解释 | 生成目标文件 vs 边翻译边执行 |
