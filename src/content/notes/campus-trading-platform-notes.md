## 背景

软件交互设计课程的团队项目。做一个校园内的二手交易平台，学生可以发布闲置物品、搜索浏览、在线聊天议价、模拟支付。多人协作，前后端分离。

## 技术栈

- **后端**：Java + Spring + Spring MVC + MyBatis（SSM）
- **前端**：HTML + CSS + JavaScript + Ajax
- **数据库**：MySQL
- **开发工具**：IDEA + Maven + Git

## 核心功能

1. **用户系统**：手机号注册（验证码）、登录、忘记密码、个人信息管理
2. **商品管理**：发布（标题/价格/图片/描述/分类）、编辑、下架、状态管理
3. **搜索浏览**：按分类、价格区间、关键词搜索；排序（最新/最热/价格）
4. **交易流程**：收藏、加入购物车、下单、模拟支付
5. **即时聊天**：买卖双方在线沟通，消息通知
6. **评价系统**：交易完成后互评
7. **个人中心**：我的发布、我的购买、我的收藏、消息通知

## 架构

```
前端（HTML + Ajax）
  │ /api 代理
后端（Spring MVC）
  ├── Controller（用户/商品/订单/消息）
  ├── Service（业务逻辑）
  └── DAO（MyBatis Mapper）
        │
        └── MySQL
```
