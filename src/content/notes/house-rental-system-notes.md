## 背景

软件工程基础课程的大作业项目。目标是做一个功能完整的房屋租赁平台，覆盖用户管理、房源、搜索推荐、租赁流程、报表统计等核心模块。

## 技术栈

- **后端**：Python + Flask + SQLAlchemy + MySQL
- **前端**：HTML 模板 + CSS + JavaScript
- **部署**：Docker + docker-compose + HTTPS
- **测试**：pytest + 并发压测脚本

## 核心功能

1. **用户管理**：房东 / 租客 / 管理员三类角色，密码加密，邮箱注册验证
2. **房源管理**：发布 / 编辑 / 下架 / 图片视频链接 / 状态管理
3. **智能搜索**：按地区、商圈、小区、户型、租金搜索，按推荐分排序
4. **智能推荐**：根据地区、户型、租金、用户历史和浏览热度计算推荐分
5. **智能代理回复**：自动回答租金、面积、户型、预约、维修等常见问题
6. **租赁流程**：预约看房 → 房东确认 → 在线合同 → 租金账单 → 模拟支付
7. **维修投诉**：租客提交，房东 / 管理员处理
8. **报表统计**：出租率、租金收入、用户活跃度、CSV 导出、统计图表
9. **系统监控**：系统日志、管理员查看操作记录

## 架构

```
Flask App
├── 用户模块（注册/登录/角色权限）
├── 房源模块（CRUD/搜索/推荐）
├── 租赁模块（预约/合同/支付）
├── 消息模块（留言/新闻/通知）
├── 报表模块（统计/图表/导出）
└── 系统模块（日志/监控/邮件）
```
