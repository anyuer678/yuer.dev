## 背景

期末复习时手里有大量 PDF 题目，但 PDF 不是题库——没法随机抽题、没法记录错题。想要一个打开就能刷、能自测的工具。

## 做了什么

考前做了 4 个单文件刷题工具（HTML + JSON 题库，浏览器直接打开即用）：

- **Linux 刷题系统** / **Linux 新题库**：Linux 基础与命令
- **开源操作系统复习系统**：操作系统概念与真题
- **数据库原理刷题系统**：数据库原理题库（611KB 题库 JSON 单独存放）
- **数字电路 mock 考试**：数电模拟考（digital-design-cpu-mock-exam）

## 关键点

- **单文件**：一个 HTML 文件自带逻辑，题库 JSON 外置或内嵌，打开即用、无需安装
- **面向真实需求**：题库来自课堂 PPT 和复习资料，给自己刷，也给同学用
- **顺带解决"PDF 不是题库"的问题**：PDF → 识别题目 → 拆分题干/选项/答案 → 结构化题库 JSON，这条链是这类工具的核心

## 现状

工具本身可用，属于"期末应急"型项目——功能够用就停，没有继续加花活。
