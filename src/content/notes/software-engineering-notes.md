## 第1章 软件工程概述

| 知识点 | 核心 |
|--------|------|
| 软件危机 | 开发成本高、周期长、质量差、维护难 |
| 软件工程三要素 | 方法、工具、过程 |
| 软件生命周期 | 问题定义→可行性研究→需求分析→设计→编码→测试→维护 |
| 软件开发模型 | 瀑布、增量、螺旋、喷泉、敏捷 |

**开发模型对比：**

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| 瀑布 | 线性顺序，文档驱动 | 需求明确 |
| 增量 | 分批交付，每次增加功能 | 可分阶段交付 |
| 螺旋 | 风险驱动，迭代开发 | 大型高风险项目 |
| 敏捷 | 快速迭代，客户参与 | 需求多变 |

## 第4章 系统设计

| 知识点 | 核心 |
|--------|------|
| 概要设计 | 模块划分、接口设计 |
| 详细设计 | 模块内部逻辑 |
| 模块独立性 | 耦合（低好）+ 内聚（高好） |
| 设计模式 | 创建型、结构型、行为型 |

**耦合从低到高：**
非直接耦合→数据耦合→标记耦合→控制耦合→外部耦合→公共耦合→内容耦合

**内聚从低到高：**
偶然内聚→逻辑内聚→时间内聚→过程内聚→通信内聚→顺序内聚→功能内聚

## 第5章 UML建模

| 图 | 用途 |
|------|------|
| 用例图 | 功能需求，参与者+用例 |
| 类图 | 静态结构，类+关系 |
| 顺序图 | 对象交互的时间顺序 |
| 活动图 | 工作流程，并行处理 |
| 状态图 | 对象状态转换 |
| 组件图 | 软件组件依赖 |
| 部署图 | 物理部署 |

**UML关系：**
- 泛化（继承）：空心三角箭头
- 实现（接口）：虚线空心三角
- 关联：实线箭头
- 聚合：空心菱形
- 组合：实心菱形
- 依赖：虚线箭头

## 第6章 软件测试

| 知识点 | 核心 |
|--------|------|
| 黑盒测试 | 不看代码，按功能测试：等价类、边界值、因果图 |
| 白盒测试 | 看代码，按结构测试：语句覆盖、判定覆盖、条件覆盖 |
| 单元测试 | 模块级别 |
| 集成测试 | 模块组合 |
| 系统测试 | 整个系统 |
| 验收测试 | 用户验收 |

**测试覆盖强度：**
语句覆盖 < 判定覆盖 < 条件覆盖 < 判定/条件覆盖 < 条件组合覆盖

## 核心对比速查表

| 编号 | A | vs | B | 一句话 |
|------|---|----|---|--------|
| 1 | 黑盒 | 白盒 | 按功能 vs 按结构 |
| 2 | 耦合 | 内聚 | 模块间独立 vs 模块内功能单一 |
| 3 | 瀑布 | 敏捷 | 线性文档驱动 vs 快速迭代 |
| 4 | 聚合 | 组合 | 部分可独立 vs 部分不可独立 |
