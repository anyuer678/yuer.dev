## 背景

键盘打字有时候是多余的——想给命令行和 MCP 加一层本地语音入口：说一句话，它听懂、执行、再播报结果。

## 做了什么

语音控制台雏形，链路分五层：STT 识别 → 意图解析 → `mcp_server.py` 注册 5 个工具（run_cli / find_file / open_folder / speak / confirm）→ 安全校验 → 执行并 TTS 播报。

## 关键点

- **安全模型**：命令先过空值/注入字符检查，再查黑名单、白名单，剩下的必须语音确认；二阶段确认 30 秒超时自动取消，执行统一超时 10 秒
- **本地优先**：STT 用 faster-whisper（首次运行下载 base 模型约 150MB），TTS 用 edge-tts，失败自动降级系统播报
- **使用方式**：`Ctrl+Shift+Space` 录音、`Ctrl+Shift+Q` 退出；`main.py --text` 可免麦克风、免管理员演示
- **Web 面板**：标准库 http.server，零第三方依赖，只监听 127.0.0.1
- **细节**：低置信（低于 0.55）或没听清时只播报"没听懂，请再说一次"，不执行；密钥走环境变量

## 现状

雏形链路完整，测试覆盖了安全门、意图解析、执行体、STT、MCP 真实 stdio 子进程握手；`keyboard` 热键模式在 Windows 需要管理员权限运行，是使用上的门槛。
