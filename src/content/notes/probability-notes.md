## 第1章 随机事件与概率

| 知识点 | 核心 |
|--------|------|
| 概率公理 | P(Ω)=1, P(∅)=0, P(A∪B)=P(A)+P(B)-P(AB) |
| 条件概率 | P(A|B) = P(AB)/P(B) |
| 乘法公式 | P(AB) = P(A)P(B|A) = P(B)P(A|B) |
| 全概率公式 | P(A) = ΣP(Bᵢ)P(A|Bᵢ) |
| 贝叶斯公式 | P(Bⱼ|A) = P(Bⱼ)P(A|Bⱼ) / ΣP(Bᵢ)P(A|Bᵢ) |
| 独立性 | P(AB) = P(A)P(B) |
| 互斥性 | AB = ∅，P(A∪B) = P(A)+P(B) |

**概率公式选择口诀：**
- 求"且"用乘法，求"或"用加法
- 求"已知结果找原因"用贝叶斯
- 求"原因导致结果"用全概率

## 第2章 随机变量及其分布

| 分布 | 概率/密度 | 期望 | 方差 | 记忆 |
|------|-----------|------|------|------|
| 二项 B(n,p) | C(n,k)pᵏ(1-p)ⁿ⁻ᵏ | np | np(1-p) | n次独立重复试验 |
| 泊松 P(λ) | λᵏe⁻λ/k! | λ | λ | 稀有事件，λ=np |
| 均匀 U(a,b) | 1/(b-a) | (a+b)/2 | (b-a)²/12 | 区间等可能 |
| 指数 Exp(λ) | λe⁻λx | 1/λ | 1/λ² | 无记忆性 |
| 正态 N(μ,σ²) | 标准化Φ(x) | μ | σ² | 钟形曲线 |

**分布之间的关系：**
- n→∞, p→0, np=λ → 二项≈泊松
- n→∞ → 二项≈正态（中心极限定理）

## 第3章 多维随机变量

| 知识点 | 核心 |
|--------|------|
| 联合分布 | F(x,y) = P(X≤x, Y≤y) |
| 边缘分布 | 对联合分布积分/求和 |
| 条件分布 | f(x|y) = f(x,y)/fᵧ(y) |
| 独立性 | f(x,y) = fₓ(x)·fᵧ(y) |

**Z = X + Y 的分布：**
- 卷积公式：fz(z) = ∫fₓ(x)fᵧ(z-x)dx
- 正态：X~N(μ₁,σ₁²), Y~N(μ₂,σ₂²) → Z~N(μ₁+μ₂, σ₁²+σ₂²)

## 第4章 数字特征

| 知识点 | 公式 |
|--------|------|
| 期望 | E(X) = Σxᵢpᵢ 或 ∫xf(x)dx |
| 方差 | D(X) = E(X²)-[E(X)]² |
| 标准差 | σ = √D(X) |
| 协方差 | Cov(X,Y) = E(XY)-E(X)E(Y) |
| 相关系数 | ρ = Cov(X,Y)/(σₓσᵧ) |
| 线性性质 | E(aX+b) = aE(X)+b |
| 方差性质 | D(aX+b) = a²D(X) |

**常见分布的期望方差：**
| 分布 | E(X) | D(X) |
|------|------|------|
| B(n,p) | np | npq |
| P(λ) | λ | λ |
| U(a,b) | (a+b)/2 | (b-a)²/12 |
| Exp(λ) | 1/λ | 1/λ² |
| N(μ,σ²) | μ | σ² |

| 定理 | 内容 |
|------|------|

## 第6章 数理统计

| 知识点 | 核心 |
|--------|------|
| 样本均值 | X̄ = ΣXᵢ/n |
| 样本方差 | S² = Σ(Xᵢ-X̄)²/(n-1) |
| χ²分布 | n个标准正态的平方和 |
| t分布 | 标准正态/√(χ²/n) |
| F分布 | 两个χ²之比 |
