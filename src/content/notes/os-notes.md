# 操作系统速记

---

## 第一章 操作系统概述

### 1.1 OS定义与功能

| 项目 | 内容 |
|------|------|
| **定义** | 管理计算机硬件与软件资源的系统软件，是用户与计算机之间的接口 |
| **两大作用** | ①资源管理（CPU、内存、设备、文件）②提供接口（命令、程序、图形） |
| **基本功能** | 处理机管理、存储器管理、设备管理、文件管理、用户接口 |
| **特征** | 并发性、共享性、虚拟性、异步性 |

### 1.2 OS发展

| 阶段 | 特点 | 关键技术 |
|------|------|----------|
| 手工操作 | 无OS，人工干预 | 无 |
| 单道批处理 | 一次一个作业，内存利用率低 | 早期监控程序 |
| 多道批处理 | 多个程序并发，资源利用率高 | 中断、通道 |
| 分时系统 | 多用户交互，响应时间短 | 时间片轮转 |
| 实时系统 | 响应及时，可靠性高 | 硬/软实时 |

### 1.3 OS结构

- **整体结构**：无模块化，代码直接调用
- **模块化结构**：划分模块，接口明确（高内聚低耦合）
- **分层结构**：自底向上分层，便于调试
- **微内核结构**：核心功能最小化，服务在用户态运行
- **外核结构**：内核分离硬件访问与策略决策

## 第二章 进程管理

### 2.1 进程与线程

| 对比项 | 进程 | 线程 |
|--------|------|------|
| **定义** | 程序的一次执行 | 轻量级进程，进程内的执行单元 |
| **资源** | 拥有独立地址空间 | 共享进程地址空间 |
| **开销** | 创建/切换开销大 | 创建/切换开销小 |
| **通信** | 需要IPC机制 | 直接读写共享变量 |
| **独立性** | 相互独立 | 一个崩溃可能影响同进程线程 |

### 2.2 进程状态

```
      创建
       ↓
      就绪 ←─────┐
       ↓         │
      运行 ──→ 阻塞
       ↓    ↑
      终止   完成I/O后唤醒
```

| 状态 | 说明 |
|------|------|
| **创建态** | 新建进程，尚未进入就绪队列 |
| **就绪态** | 已获得除CPU外所有资源，等待调度 |
| **运行态** | 正在CPU上执行 |
| **阻塞态** | 等待某事件（如I/O），无法执行 |
| **终止态** | 执行完毕或被撤销 |

### 2.3 PCB（进程控制块）

PCB是进程存在的唯一标识，包含：

| 字段 | 说明 |
|------|------|
| 进程标识符（PID） | 唯一标识 |
| 进程状态 | 当前状态 |
| 程序计数器 | 下一条指令地址 |
| CPU寄存器 | 进程中断时的现场信息 |
| CPU调度信息 | 优先级、队列指针 |
| 内存管理信息 | 页表、段表 |
| 资源清单 | 打开文件、已分配设备 |
| 进程间通信信息 | 消息队列、信号量 |

### 2.4 进程同步

**临界资源**：一次只能被一个进程访问的资源

**临界区管理四原则**：

1. **互斥进入**：临界区一次只允许一个进程
2. **有限等待**：不能无限等待进入临界区
3. **空闲让进**：临界区空闲时允许进入
4. **让权等待**：不能进入时释放CPU

### 2.5 PV操作

```c
// P操作（等待/申请）
P(S) {
    S--;
    if (S < 0) {
        将进程加入等待队列;
        阻塞;
    }
}

// V操作（释放/通知）
V(S) {
    S++;
    if (S <= 0) {
        从等待队列取出一个进程;
        唤醒;
    }
}
```

**信号量含义**：
- `S > 0`：还有 `S` 个资源可用
- `S = 0`：资源恰好用完
- `S < 0`：有 `|S|` 个进程在等待

### 2.6 死锁

| 项目 | 内容 |
|------|------|
| **定义** | 两个或多个进程因竞争资源而造成的一种互相等待的僵局 |
| **四个必要条件** | 互斥条件、请求与保持条件、不可剥夺条件、循环等待条件 |
| **预防** | 破坏四个必要条件之一（静态分配、一次性申请等） |
| **避免** | 银行家算法（在资源分配时检查安全性） |
| **检测** | 资源分配图化简 |
| **恢复** | 终止进程、资源回滚 |

**银行家算法核心**：
```
Available + Allocation >= Need  →  可以分配（安全）
Available + Allocation < Need   →  不可分配（不安全）
```

## 第三章 处理机调度

### 3.1 调度层次

| 层次 | 调度对象 | 频率 | 装换开销 |
|------|----------|------|----------|
| **作业调度** | 作业（宏观） | 低 | 大 |
| **进程调度** | 进程（微观） | 高 | 小 |
| **中级调度** | 内存与外存交换 | 中 | 中 |

### 3.2 调度算法对比

| 算法 | 先来先服务(FCFS) | 短作业优先(SJF) | 时间片轮转(RR) | 优先级调度 | 多级反馈队列 |
|------|------------------|-----------------|----------------|------------|--------------|
| **原则** | 到达顺序 | 作业长度 | 时间片轮转 | 优先级高低 | 多队列+动态调整 |
| **能否抢占** | 否 | 可抢占(SRTN) | 是 | 可抢占 | 是 |
| **优点** | 公平简单 | 平均等待时间最短 | 响应快、公平 | 灵活 | 综合性好 |
| **缺点** | 对短作业不利 | 长作业可能饥饿 | 时间片选择关键 | 可能饥饿 | 实现复杂 |
| **适用** | 批处理 | 批处理 | 分时系统 | 通用 | 通用 |

### 3.3 计算公式

| 指标 | 公式 |
|------|------|
| **周转时间** | `T = 完成时间 - 到达时间` |
| **带权周转时间** | `W = 周转时间 / 运行时间` |
| **平均周转时间** | `ΣT / n` |
| **平均等待时间** | `Σ等待时间 / n` |

## 第四章 内存管理

### 4.1 内存分配方式

| 方式 | 说明 | 特点 |
|------|------|------|
| **连续分配** | 整块内存分配 | 碎片严重 |
| **固定分区** | 预先划分固定大小分区 | 内部碎片 |
| **动态分区** | 按需分配，大小可变 | 外部碎片 |
| **分页** | 固定划分页面，离散分配 | 无外部碎片，有内部碎片 |
| **分段** | 按逻辑单元划分，大小可变 | 便于共享和保护，有外部碎片 |
| **段页式** | 先分段再分页 | 结合两者优点 |

### 4.2 分页存储

| 概念 | 公式/说明 |
|------|-----------|
| **逻辑地址** | 页号 + 页内偏移 |
| **物理地址** | 帧号 + 页内偏移 |
| **页表** | 逻辑页号 → 物理帧号 |
| **地址转换** | 物理地址 = 页表项(帧号) × 页面大小 + 页内偏移 |

**多级页表**：解决页表过大问题，以时间换空间

**快表（TLB）**：缓存常用页表项，提高地址转换速度

### 4.3 虚拟内存

| 特征 | 说明 |
|------|------|
| **局部性原理** | 时间局部性（循环）、空间局部性（顺序访问） |
| **请求分页** | 页表增加状态位（驻留位）、访问位、修改位 |
| **缺页中断** | 访问页面不在内存时触发，可能淘汰页面 |
| **抖动（颠簸）** | 频繁缺页，系统效率急剧下降 |

### 4.4 页面置换算法对比

| 算法 | 思路 | 特点 |
|------|------|------|
| **最佳置换(OPT)** | 淘汰将来最长时间不用的 | 最优但无法实现 |
| **先进先出(FIFO)** | 淘汰最早进入内存的 | 简单，可能产生Belady异常 |
| **最近最久未使用(LRU)** | 淘汰最近最久没用的 | 性能好，实现开销大 |
| **时钟算法(Clock)** | LRU近似，使用访问位 | 性能接近LRU，开销小 |
| **改进型时钟** | 考虑访问位+修改位 | 进一步减少I/O |

**Belady异常**：FIFO算法中，分配帧数增加但缺页次数反而增加的现象

### 4.5 记忆口诀

> **页面置换算法口诀**：
> 最佳最优不可选，FIFO简单有异常，
> LRU性能最好但开销大，时钟算法来折中

## 第五章 文件系统

### 5.1 文件结构

| 结构类型 | 说明 |
|----------|------|
| **顺序结构** | 连续存放，访问快但插入删除难 |
| **链接结构** | 用指针链接，灵活但访问慢 |
| **索引结构** | 用索引块映射，兼顾灵活性和速度 |

**多级索引**：UNIX inode结构，直接块+一级间接+二级间接+三级间接

### 5.2 目录结构

| 结构 | 特点 |
|------|------|
| **单级目录** | 所有文件放一起，简单但不允许重名 |
| **两级目录** | 用户目录+文件目录 |
| **树形目录** | 多级层次结构，当前最常用 |
| **图形目录** | 允许共享，有环 |

### 5.3 磁盘调度算法对比

| 算法 | 策略 | 平均寻道 | 特点 |
|------|------|----------|------|
| **FCFS** | 按请求顺序 | 高 | 公平但效率低 |
| **SSTF** | 最短寻道时间优先 | 较低 | 可能饥饿 |
| **SCAN（电梯）** | 来回扫描 | 较低 | 边缘请求等待久 |
| **C-SCAN** | 单向扫描+跳回 | 较低 | 等待时间均匀 |
| **LOOK** | SCAN变体，不必到端 | 低 | 实际中最常用 |
| **C-LOOK** | C-SCAN变体 | 低 | 综合性能好 |

> **磁盘调度口诀**：
> FCFS公平跑得慢，SSTF快但有饥饿，
> SCAN像电梯来回走，C-SCAN单向更均匀，
> LOOK不到端头就折返，C-LOOK折中性能佳

## 第六章 I/O管理

### 6.1 I/O控制方式

| 方式 | 特点 | 适用场景 |
|------|------|----------|
| **程序直接控制** | CPU忙等，效率低 | 简单低速设备 |
| **中断驱动** | I/O完成后中断通知CPU | 中速设备 |
| **DMA** | 直接内存访问，批量传输 | 高速设备（磁盘） |
| **通道** | 专用I/O处理器，自主控制 | 大型机、服务器 |

### 6.2 缓冲技术

| 缓冲方式 | 说明 |
|----------|------|
| **单缓冲** | 一个缓冲区，CPU与设备交替使用 |
| **双缓冲** | 两个缓冲区，可并行工作 |
| **循环缓冲** | 多个缓冲区轮流使用 |
| **缓冲池** | 系统公用缓冲区，按类型管理 |

### 6.3 SPOOLing技术

| 项目 | 说明 |
|------|------|
| **定义** | 假脱机技术，将独占设备改造为共享设备 |
| **原理** | 在磁盘上开辟缓冲区，模拟脱机操作 |
| **经典应用** | 打印机管理（将待打印数据存入磁盘缓冲区） |
| **优点** | 提高设备利用率，减少用户等待 |

### 6.4 磁盘访问时间

```
总时间 = 寻道时间 + 旋转延迟 + 传输时间

- 寻道时间：磁头移动到目标磁道
- 旋转延迟：等待目标扇区旋转到磁头下（平均 = 半圈时间）
- 传输时间：数据读写时间
```

## 综合速查表

### 进程 vs 线程

| 维度 | 进程 | 线程 |
|------|------|------|
| 资源 | 独立地址空间 | 共享地址空间 |
| 通信 | IPC（管道/消息/共享内存） | 直接读写 |
| 开销 | 重 | 轻 |
| 安全性 | 高 | 低（相互影响） |
| 适用 | 并发执行不同程序 | 同一程序内并行 |

### 同步机制对比

| 机制 | 优点 | 缺点 |
|------|------|------|
| **互斥锁** | 简单 | 可能忙等 |
| **信号量** | 功能强大 | 易出错（死锁） |
| **管程** | 易于使用 | 实现复杂 |
| **消息传递** | 适合分布式 | 通信开销 |

### 死锁处理策略对比

| 策略 | 时机 | 开销 | 资源利用 |
|------|------|------|----------|
| **预防** | 事前 | 低 | 低 |
| **避免** | 事中 | 中 | 中 |
| **检测+恢复** | 事后 | 高 | 高 |
| **鸵鸟（忽略）** | - | 最低 | 最高 |

### 存储管理对比

| 方式 | 内部碎片 | 外部碎片 | 地址转换 | 特点 |
|------|----------|----------|----------|------|
| **固定分区** | 有 | 无 | 简单 | 分区数固定 |
| **动态分区** | 无 | 有 | 中等 | 灵活但需压缩 |
| **分页** | 有 | 无 | 快（TLB） | 最常用 |
| **分段** | 无 | 有 | 中等 | 便于共享 |
| **段页式** | 有 | 无 | 慢 | 综合 |

## 核心考点速记

1. **进程与线程的本质区别**：资源拥有 vs 执行单位
2. **PV操作的核心**：P申请资源(S--)，V释放资源(S++)
3. **死锁的四个条件**：互斥、请求保持、不可剥夺、循环等待
4. **银行家算法**：分配前检查分配后是否安全
5. **分页无外部分配、分段有外部分配**
6. **LRU需要硬件支持**（栈或计数器）
7. **FIFO的Belady异常**：唯一满足包含性原则的算法
8. **SPOOLing本质**：用磁盘空间模拟脱机操作
9. **DMA传输数据不经过CPU**
10. **磁盘调度看寻道时间**，SCAN和C-SCAN是重点
