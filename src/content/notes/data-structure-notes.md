## 第1章 绪论

| 知识点 | 核心 |
|--------|------|
| 数据结构定义 | 数据元素之间的**关系**和**运算** |
| 逻辑结构 | 集合、线性、树形、图状（网状） |
| 物理结构 | 顺序存储、链式存储、索引、散列 |
| 算法特性 | 有穷性、确定性、可行性、输入、输出 |
| 时间复杂度 | `O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)` |
| 空间复杂度 | 算法执行过程中所需的额外存储空间 |

## 第2章 线性表

| 知识点 | 核心 |
|--------|------|
| 顺序表 | 连续存储，随机访问O(1)，插入删除O(n) |
| 单链表 | 不连续存储，插入删除O(1)（已知位置），查找O(n) |
| 双链表 | 前驱+后继，可双向遍历 |
| 循环链表 | 尾节点指向头节点，判断条件 `p->next == head` |
| 静态链表 | 用数组模拟链表，适合无指针的语言 |

**顺序表 vs 链表对比表：**

| 比较项 | 顺序表 | 链表 |
|--------|--------|------|
| 存储方式 | 连续 | 不连续 |
| 随机访问 | ✅ O(1) | ❌ O(n) |
| 插入/删除 | O(n) | O(1)（已知位置） |
| 空间 | 预分配，可能浪费 | 动态分配，按需 |
| 缓存友好 | ✅ | ❌ |

## 第3章 栈和队列

| 知识点 | 核心 |
|--------|------|
| 栈 | 后进先出 LIFO，操作：push/pop/top |
| 队列 | 先进先出 FIFO，操作：enqueue/dequeue |
| 循环队列 | 解决假溢出，`Q.rear - Q.front + MAXSIZE) % MAXSIZE` |
| 队列长度 | `(rear - front + MAXSIZE) % MAXSIZE` |
| 两栈共享 | 两个栈共享一个数组，栈1从左往右，栈2从右往左 |
| 应用 | 括号匹配、表达式求值、进制转换、递归 |

## 第4章 串

| 知识点 | 核心 |
|--------|------|
| 朴素匹配 | O(nm)，每次失配主串指针回溯 |
| KMP算法 | O(n+m)，主串指针不回溯，利用next数组 |
| next数组 | `next[j]` 表示模式串j位置失配时的下一个匹配位置 |
| nextval数组 | 对next的优化，避免多余比较 |

## 第5章 树与二叉树

| 知识点 | 核心 |
|--------|------|
| 二叉树 | 每个节点最多两棵子树 |
| 满二叉树 | 每层节点数都达到最大 |
| 完全二叉树 | 只有最后一层可能不满，且从左到右连续 |
| 前序遍历 | **根**→左→右 |
| 中序遍历 | 左→**根**→右 |
| 后序遍历 | 左→右→**根** |
| 层序遍历 | BFS，用队列实现 |
| 节点数 | n₀ = n₂ + 1（叶子数 = 度为2的节点数 + 1） |
| 二叉排序树 | 左 < 根 < 右，中序遍历为有序序列 |
| 平衡二叉树 | 任意节点左右子树高度差 ≤ 1 |
| 哈夫曼树 | 带权路径长度WPL最小的二叉树，用于编码 |

**遍历还原二叉树：**
- 前序+中序 → 可唯一确定
- 后序+中序 → 可唯一确定
- 前序+后序 → 不能唯一确定

## 第6章 图

| 知识点 | 核心 |
|--------|------|
| 存储结构 | 邻接矩阵、邻接表、十字链表、邻接多重表 |
| DFS | 深度优先搜索，用栈（递归） |
| BFS | 广度优先搜索，用队列 |
| 最小生成树 | Prim（点贪心）、Kruskal（边贪心） |
| 最短路径 | Dijkstra（单源）、Floyd（多源） |
| 拓扑排序 | AOV网，找入度为0的节点 |
| 关键路径 | AOE网，最长路径，决定工程最短工期 |

**Prim vs Kruskal对比：**

| 比较项 | Prim | Kruskal |
|--------|------|---------|
| 贪心策略 | 点（从顶点出发） | 边（从边出发） |
| 时间复杂度 | O(n²) | O(e log e) |
| 适用场景 | 稠密图 | 稀疏图 |

## 第7章 查找

| 知识点 | 核心 |
|--------|------|
| 顺序查找 | O(n)，无序表 |
| 二分查找 | O(log n)，有序表 |
| 二叉排序树 | 平均O(log n)，最坏O(n) |
| 平衡二叉树 | O(log n)，严格平衡 |
| B树 | 多路平衡搜索树，用于磁盘 |
| B+树 | 叶子节点存数据，非叶子只存索引，用于数据库索引 |
| 散列表 | O(1)平均，冲突解决：开放定址、链地址法 |

## 第8章 排序

| 算法 | 最好 | 最坏 | 平均 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | ❌ |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 希尔排序 | O(n log n) | O(n²) | O(n^1.3) | O(1) | ❌ |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ |
| 快速排序 | O(n log n) | O(n²) | O(n log n) | O(log n) | ❌ |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ❌ |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✅ |

**口诀：快些选堆，归并稳定**
- **快**速排序、**些**尔排序、**选**择排序、**堆**排序 → 不稳定
- **归**并排序 → 稳定

## 核心对比速查表

| 编号 | A | vs | B | 一句话 |
|------|---|----|---|--------|
| 1 | 顺序表 | 链表 | 连续随机访问 vs 不连续插入删除快 |
| 2 | 栈 | 队列 | LIFO vs FIFO |
| 3 | DFS | BFS | 栈/递归 vs 队列 |
| 4 | Prim | Kruskal | 点贪心 vs 边贪心 |
| 5 | Dijkstra | Floyd | 单源 vs 多源 |
| 6 | 二叉排序树 | 平衡二叉树 | 可能退化 vs 严格平衡 |
| 7 | B树 | B+树 | 数据在所有节点 vs 数据在叶子 |
| 8 | 快速排序 | 归并排序 | 不稳定 vs 稳定 |
