## 数据类型与存储

| 知识点 | 核心 |
|--------|------|
| 字节 | BYTE(8位)，DB定义 |
| 字 | WORD(16位)，DW定义 |
| 双字 | DWORD(32位)，DD定义 |
| 存储顺序 | 小端存储（低字节在低地址） |

---

## 寻址方式

| 寻址方式 | 格式 | 说明 |
|----------|------|------|
| 立即寻址 | `MOV AX, 1234H` | 操作数直接在指令中 |
| 寄存器寻址 | `MOV AX, BX` | 操作数在寄存器中 |
| 直接寻址 | `MOV AX, [2000H]` | 操作数在内存，地址在指令中 |
| 寄存器间接 | `MOV AX, [BX]` | 地址在寄存器中 |
| 基址变址 | `MOV AX, [BX+SI]` | 基址+变址 |
| 相对基址变址 | `MOV AX, [BX+SI+10H]` | 基址+变址+位移量 |

## 常用指令

| 类型 | 指令 |
|------|------|
| 数据传送 | MOV, PUSH, POP, XCHG, LEA |
| 算术运算 | ADD, SUB, MUL, DIV, INC, DEC |
| 逻辑运算 | AND, OR, NOT, XOR, TEST |
| 移位 | SHL, SHR, SAR, ROL, ROR |
| 串操作 | MOVS, CMPS, SCAS, LODS, STOS |
| 控制转移 | JMP, JZ/JNZ, JC/JNC, CALL, RET |

**条件跳转：**
| 指令 | 条件 | 含义 |
|------|------|------|
| JZ/JE | ZF=1 | 等于/为零 |
| JNZ/JNE | ZF=0 | 不等于/不为零 |
| JC/JB | CF=1 | 进位/低于 |
| JNC/JNB | CF=0 | 无进位/不低于 |
| JS | SF=1 | 结果为负 |
| JO | OF=1 | 溢出 |

## 堆栈操作

| 操作 | 指令 | 说明 |
|------|------|------|
| 压栈 | PUSH AX | SP←SP-2, [SP]←AX |
| 出栈 | POP AX | AX←[SP], SP←SP+2 |

---

## 子程序与中断

| 知识点 | 核心 |
|--------|------|
| CALL | 保护断点(压栈)，跳转到子程序 |
| RET | 恢复断点(出栈)，返回调用者 |
| 中断 | 保护断点+标志寄存器，转中断服务程序 |
| IRET | 恢复标志寄存器+断点，返回被中断程序 |

**DOS中断：**
| 中断号 | 功能 |
|--------|------|
| INT 21H | DOS系统调用 |
| AH=01H | 键盘输入字符 |
| AH=02H | 显示字符 |
| AH=09H | 显示字符串 |
| AH=4CH | 程序退出 |

## 核心对比速查表

| 编号 | A | vs | B | 一句话 |
|------|---|----|---|--------|
| 1 | MOV | LEA | 传送数据 vs 加载有效地址 |
| 2 | CALL | JMP | 保存返回地址 vs 不保存 |
| 3 | MUL | DIV | 无符号乘法 vs 无符号除法 |
| 4 | SHL | SHR | 逻辑左移(×2) vs 逻辑右移(÷2) |
