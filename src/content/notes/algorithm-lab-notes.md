## 实验一：分治算法

分治三步：**分解 → 求解 → 合并**。三个题目：归并排序、快速排序、循环赛日程表。

- 归并排序：递归拆半，合并两个有序数组，稳定，O(n log n)
- 快速排序：选基准（实验用首元素），partition 后左右递归
- 循环赛日程表：n=2^k 个运动员两两比赛，把大表递归拆成 2×2 小表，再合并填充

日程表合并的填充规律（核心代码）：

```cpp
// 右上 = 左上 + half；左下 = 右上；右下 = 左上
schedule[i][j] = schedule[i][j - half] + half;
schedule[i + half][j - half] = schedule[i][j];
schedule[i + half][j] = schedule[i][j - half];
```

注意：**n 必须是 2 的幂**，代码里用 `(n & (n - 1)) == 0` 判断。

## 实验二：贪心算法

贪心核心：每一步选当前局部最优，靠"贪心选择性质 + 最优子结构"保证全局最优。三个题目：Dijkstra、贪心找零、多机调度。

- **Dijkstra 单源最短路径**：每次选"未访问且距离源点最近"的顶点，松弛其邻接点；**不支持负权边**
- **贪心找零**：从 25、10、5、1 分硬币里尽可能取大面值。注意：**只有规范面值系（如 25/10/5/1）才最优**，加个 15 分硬币贪心就失效
- **多机调度**：作业按加工时间**降序**，每次分给当前负载最小的机器，是近似最优（LPT 思路）

```cpp
sort(jobs.rbegin(), jobs.rend());
for (int i = 0; i < n; i++) {
    // 找负载最小的机器 idx，machines[idx] += jobs[i];
}
```

## 实验三：动态规划

动态规划两个特征：**最优子结构 + 重叠子问题**，用表存子问题解避免重复计算。

- **0-1 背包**（N=5, C=10, w={2,2,6,5,4}, v={6,3,5,4,6}）：

```cpp
// dp[i][j] = 前 i 个物品、容量 j 的最大价值
if (j < w[i-1]) dp[i][j] = dp[i-1][j];
else dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i-1]] + v[i-1]);
```

回溯选中的物品：从 dp[N][C] 倒推，`dp[i][remain] != dp[i-1][remain]` 说明第 i 个被选中。

- **合唱队形**：N 位同学身高，求最少出列人数使剩余呈"先升后降"队形。实验里简化为"去掉重复身高"，即问题拆成找最长递增后再递减的子序列（对题意的简化处理）

## 实验四：回溯法

回溯 = **试探 → 剪枝 → 回退**，递归遍历所有候选。三个题目：八皇后、批处理作业调度（Johnson）、数字全排列。

- **八皇后**：`isSafe` 检查同列与对角线（`abs(i-row) == abs(pos[i]-col)`），逐行放皇后
- **批处理作业调度**：两台机器流水作业最小总完成时间，用 Johnson 规则排序（`min(a.t1,b.t2) < min(b.t1,b.t2)`），完成时间递推：

```cpp
F1[i] = F1[i-1] + t1[i];              // 作业 i 在机器 1 的完成时间
F2[i] = max(F1[i], F2[i-1]) + t2[i];  // 机器 2 要等机器 1 或前一作业
```

这个 F1/F2 递推一开始逻辑混乱，手工算 n=3 样例才理清。

- **数字全排列**：`used[]` 标记 + 路径回溯，`n!` 种

## 实验五：三种算法对比解 0-1 背包

同一道 0-1 背包用贪心、回溯、分支限界各解一次，核心差异是"精度 vs 效率"：

| 算法 | 解 | 复杂度 | 适用 |
|---|---|---|---|
| 贪心（按单位价值降序） | **近似解** | O(n log n) | 大规模、允许近似 |
| 回溯（选/不选 + 剪枝） | 精确解 | O(2^n)，剪枝后优化 | 小规模（n ≤ 20） |
| 分支限界（优先队列按上界） | 精确解 | 优于回溯，空间 O(2^n) | 中等规模、要效率 |

分支限界要点：节点存 bound（当前价值 + 剩余物品贪心价值），优先搜索上界高的节点，`bound <= 当前最优` 就剪枝。

**踩坑**：回溯法一开始没写"剩余价值 + 当前价值 <= 已找到最大值"的剪枝，n=10 直接超时；加上剪枝后大幅提速。

## 小结

五个实验走完算法主线：**分治拆问题、贪心求快解、动态规划求精确、回溯/分支限界搜索解空间**。最深的体会是剪枝和状态定义——同一道题换一种算法思路，代码量和效率差别很大。
