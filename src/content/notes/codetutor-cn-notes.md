## 背景

网上讲代码的资料要么太浅、要么太深。想做一个工具：贴一段代码进去，它按你的水平，像老师一样分块讲清楚，再出题验证。

## 做了什么

纯静态单页工具（本地双击 index.html 即用），五步教学流程：① 这段代码在做什么 → ② 分块讲解（按语义块 3-8 块，每块可"重新讲得更简单"）→ ③ 关键词汇表 → ④ 3 道选择题（答案先隐藏，作答后才显示）→ ⑤ 改写挑战。

## 关键点

- **年龄分级**：幼儿园 / 小学生 / 初中生 / 成人四档词汇表，中途切换会用新词表重新生成讲解
- **零框架零依赖**：`prompts.js`（词表 + 角色卡 + JSON 契约）、`storage.js`（localStorage 只存偏好，**不存代码**）、`llm.js`（网络唯一出口：请求/超时/契约校验/容错重试）、`state.js`（五步状态机）、`ui.js`（renderStep 纯函数）
- **隐私**：粘贴的代码只在本机浏览器内存处理，不落盘
- **可选代理**：`server.py` 解决浏览器直调部分 API 的 CORS 问题，key 从环境变量读、不出现在前端
- **快捷键**：Ctrl+Enter 开始讲解；内置"填示例"演示（幼儿园档讲 for 循环，用"三个人排队"类比）

## 现状

雏形可用，README 明确写了几条已知限制（部分 API 浏览器直调会 CORS 失败、超 30 秒提示重试、无账号体系）；测试用 pytest + node 内置测试器，零第三方依赖。
