## 第1章 数据表示

| 知识点 | 核心 |
|--------|------|
| 进制转换 | 十→二：除2取余；二→十六：4位一组 |
| 原码 | 符号位+真值绝对值，`+0≠-0` |
| 反码 | 正数=原码；负数=符号位不变，其余取反 |
| 补码 | 正数=原码；负数=反码+1，`+0=-0` |
| 移码 | 补码符号位取反，便于比较大小 |

**原码/反码/补码范围：**
| 码制 | n位范围 |
|------|---------|
| 原码 | -(2ⁿ⁻¹-1) ~ +(2ⁿ⁻¹-1) |
| 反码 | -(2ⁿ⁻¹-1) ~ +(2ⁿ⁻¹-1) |
| 补码 | -2ⁿ⁻¹ ~ +(2ⁿ⁻¹-1) |

## 第2章 运算器

| 知识点 | 核心 |
|--------|------|
| 定点整数 | 小数点固定在最低位后 |
| 定点小数 | 小数点固定在符号位后 |
| 浮点数 | N = (-1)ˢ × M × Rᵉ，S符号/M尾数/E阶码/R基数 |
| IEEE 754 | 单精度32位：1符号+8阶码+23尾数 |
| 加法器 | 串行→并行→超前进位 |
| 溢出检测 | 双符号位法：00正/11负/01上溢/10下溢 |

## 第3章 存储系统

| 知识点 | 核心 |
|--------|------|
| 存储层次 | 寄存器→Cache→主存→辅存 |
| Cache映射 | 直接映射/全相联映射/组相联映射 |
| 替换策略 | LRU/FIFO/随机 |
| 写策略 | 写回(脏页) vs 写直达 |
| 虚拟存储 | 逻辑地址→页表→物理地址 |
| RAID | 0条带/1镜像/5奇偶校验/10条带+镜像 |

**Cache映射对比：**

| 映射方式 | 块数 | 灵活性 | 硬件复杂度 |
|----------|------|--------|------------|
| 直接映射 | 每组1块 | 低 | 低 |
| 全相联 | 1组全部 | 高 | 高 |
| 组相联 | 每组n块 | 中 | 中 |

## 第6章 总线与I/O

| 知识点 | 核心 |
|--------|------|
| 总线分类 | 数据总线/地址总线/控制总线 |
| 总线仲裁 | 集中(链式/计数器) / 分布 |
| I/O方式 | 程序查询/中断/DMA/通道 |

**I/O方式对比：**

| 方式 | CPU参与度 | 传输单位 | 适用场景 |
|------|-----------|----------|----------|
| 程序查询 | 高 | 字 | 低速设备 |
| 中断 | 中 | 字 | 中速设备 |
| DMA | 低 | 块 | 高速设备 |
| 通道 | 最低 | 一组块 | 大型系统 |

## 核心对比速查表

| 编号 | A | vs | B | 一句话 |
|------|---|----|---|--------|
| 1 | 原码 | 补码 | 有+0-0 vs 统一零 |
| 2 | CISC | RISC | 复杂指令多 vs 精简指令少 |
| 3 | 直接映射 | 全相联 | 块固定位置 vs 块任意位置 |
| 4 | 写回 | 写直达 | 延迟写入 vs 立即写入 |
| 5 | 中断 | DMA | CPU搬运 vs 直接内存访问 |
