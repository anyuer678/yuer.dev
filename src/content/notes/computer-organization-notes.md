## 系统层次与性能

计算机 = 硬件（运算器、控制器、存储器、I/O 设备）+ 软件。层次自下而上：数字逻辑 → 微程序 → 机器语言 → 操作系统 → 汇编 → 高级语言 → 应用；下层为上层提供「虚拟机」抽象，**ISA 是软硬件之间的分界线**。

冯·诺依曼结构：指令和数据以二进制同存一个存储器、顺序执行、以运算器为中心；现代结构以存储器为中心、采用总线；哈佛结构指令/数据分存独立总线，可同时取指取数（用于 DSP/嵌入式）。

**性能公式**：执行时间 = 指令数 × CPI × 时钟周期 = 指令数 × CPI / 主频。Amdahl 定律：加速比 = 1 / [(1−f) + f/s]，整体提速受不可优化部分限制。

## 指令集架构 ISA

ISA 是软硬件的「契约」：定义指令集、寄存器、寻址方式、内存模型、中断异常、I/O 模型。同一 ISA 可有多种微架构实现。

**CISC vs RISC**：CISC（x86）指令多、变长、可直接访存、微码实现；RISC（ARM/MIPS/RISC-V）指令少、定长、仅 Load/Store 访存、硬连线实现。

**指令** = 操作码 + 操作数。按地址数：三地址（RISC）、二地址（x86，D = D OP S）、一地址（累加器）、零地址（栈机）。类型：数据传送（LOAD/STORE）、算术、逻辑、控制转移（JMP/条件分支/CALL/RET）、系统（TRAP/HALT）。

**寻址方式**：立即、寄存器、直接、寄存器间接、变址/基址加偏移（数组访问）、PC 相对、栈寻址。

**寄存器约定**（AAPCS）：R0-R3 传参、R0 返值、R4-R11 被调用者保存；PC、IR、标志寄存器（Z/N/C/V）。

**字节序**：大端（MSB 在低地址，网络字节序）/ 小端（LSB 在低地址，x86 用，ARM 可配）；n 字节数据地址需 n 对齐。

## ARM 架构（RISC 实例）

ARM 特点：16 个 32 位通用寄存器、Load/Store 架构、32 位定长指令（16 位 Thumb 子集提高代码密度）、几乎所有指令可条件执行、内置桶形移位器。

寄存器：R0-R12 通用、R13(SP) 栈指针、R14(LR) 链接寄存器存返回地址、R15(PC)；CPSR 含 N/Z/C/V 标志与模式位。7 种模式：User、FIQ、IRQ、SVC、Abort、Undef、System。

**常用指令**：

- 数据处理：ADD/SUB/ADC/SBC/RSB、AND/ORR/EOR/BIC（位清零）、CMP/CMN/TST/TEQ（只置标志）、MOV/MVN；S 后缀更新 CPSR
- Load/Store：LDR/STR 及变体（LDRB/LDRSB/LDRH）；前变址 `[Rn,#off]!` 与后变址 `[Rn],#off` 可更新基址
- 多寄存器：LDM/STM（`STMFD SP!,{...,LR}` / `LDMFD SP!,{...,PC}` 配对实现函数进入/返回）
- 分支：B 无条件、**BL 分支并链接**（LR=返回地址，子程序调用用）、BX/BLX 切换 ARM/Thumb

**立即数限制**：ARM 立即数必须是 8 位值循环右移偶数位得到的。**异常**：Reset/未定义指令/SWI/取指中止/数据中止/IRQ/FIQ，异常向量表固定 0x00000000 起每 4 字节一项；SWI 用于系统调用。

## 处理器：数据通路与流水线

**数据通路**：取指（PC→存储器→IR）→ 译码（寄存器堆）→ 执行（ALU）→ 访存 → 写回。控制信号由控制器（硬连线或微程序）产生。

**流水线**（经典五段「取译执访写」）：IF → ID → EX → MEM → WB。

**三类冒险**：

- 结构冒险：硬件资源冲突（如单存储器取指又访存）→ 分离指令/数据 Cache 或插入气泡
- 数据冒险：指令间数据依赖 → 转发（bypass）解决大部分，load-use 需停顿
- 控制冒险：分支跳转不确定下一条 → 分支预测、延迟槽、flush

**性能**：理想吞吐 = 时钟周期 × 指令数 / 段数；级数多 → 频率可更高，但冒险惩罚与功耗增大。ARM9 5 级、Cortex-A9 8-11 级乱序双发射。

## 存储层次：Cache 与虚拟内存

金字塔：寄存器 → Cache(SRAM) → 主存(DRAM) → 外存。靠**局部性原理**（时间局部性：刚访问的将再访问；空间局部性：邻近的将被访问）实现「容量接近主存、速度接近寄存器」。

**主存**：SRAM（触发器、不刷新、快贵，作 Cache）；DRAM（电容、需刷新、集成度高，作主存）。ROM 族：MROM/PROM/EPROM/EEPROM/Flash。

**主存扩展**（计算常考）：位扩展（片字数够、位数不够 → 并联多片凑字长，地址线不增、数据线增加）；字扩展（位数够、字数不够 → 串联多片凑容量，加高位地址线选片，片选译码）；字位扩展（两者都缺 → 先字后位）。容量 = 芯片数 × 单片容量，地址线数 = log₂(总字数)，数据线数 = 字长。

**Cache 组织**：块 = 有效位 + 标记 Tag + 数据。

- 直接映射：主存块号 mod Cache 块数（地址 = Tag|Index|Offset），简单但冲突高
- 全相联：任意放置，冲突最低但需并行比较全部标记
- 组相联：组间直接、组内全相联，n 路折中（现代主流）

**替换**：RAND/FIFO/LRU（近似 NRU）。**写策略**：写直达（同时写主存，简单一致但慢）vs 写回（仅写 Cache、替换时回写、需脏位，快但复杂）；配**写分配**（写缺失时把块调入 Cache 再写，配写回常见）或**不写分配**（写缺失只写主存/下一级，配写直达常见）。

**性能**：T_avg = h·T_cache + (1−h)·T_mem；AMAT = 命中时间 + 缺失率 × 缺失代价。现代多级 Cache：L1 核内、L2、L3 核间共享。

**虚拟内存**：虚址 = 虚页号 + 页内偏移，经页表（PTE 含有效位/物理页框号/脏位/权限位）映射为物理地址；**TLB 是页表快表**（页表在主存、TLB 在 CPU）。缺页时从磁盘调入；页面置换：OPT/FIFO/LRU/Clock。

## I/O 系统

**四种控制方式**（CPU 利用率递增）：

- 程序查询：忙等轮询，实现简单
- 中断驱动：设备就绪发中断，CPU 保存/恢复现场
- **DMA**：DMA 控制器接管总线传输，CPU 仅开始和结束时干预
- 通道：专用 I/O 处理器执行通道程序

**中断系统**：中断源 → 请求 → 判优 → 响应（关中断、存断点、转服务程序）→ 保护现场 → 服务 → 恢复现场 → 返回；分可屏蔽/不可屏蔽（NMI）、向量/非向量。**多重中断**：优先级高的可打断低级的（中断嵌套），同级互不打断；屏蔽字用于动态改变优先级。

**总线**：地址/数据/控制三类线；同步定时（统一时钟）vs 异步定时（握手）；仲裁分集中式（链式查询/计数器/独立请求）与分布式；带宽 = 总线宽度 × 频率 / 8。

**端口编址**：独立编址（x86 的 IN/OUT）vs 内存映射（ARM 用 LDR/STR 访 I/O）。

**外存与 RAID**：磁盘平均访问时间 = 寻道 + 旋转延迟 + 传输；调度 FCFS/SSTF/SCAN。RAID 0 条带（无冗余）、1 镜像、5 分布式奇偶（容一块盘）、10 组合。

## 速记口诀

- 五大部件「运控存入出」；流水线五段「取译执访写」
- Cache 映射：直接=一个萝卜一个坑、全相联=随便坐、组相联=分区随便坐
- 写直达=同步写，写回=攒着写
- 三层冒险：结构抢资源，数据等结果，控制猜不猜
- 易错点：CPI ≠ 频率；页表在主存、TLB 在 CPU
