## 背景

大二上学期操作系统课程，使用自编教材（开源操作系统），从 ARM64 视角理解 OS 原理。复习笔记覆盖 OS 发展、架构、硬件抽象、进程/内存/文件管理全链路。

## 关键内容

### OS 发展与架构

- 批处理 → 通用系统 OS/360（首个与硬件分离的 OS）→ 对称/非对称多处理器
- 四种内核架构：简要结构（MS-DOS）→ 宏内核（Unix/Linux）→ 微内核（seL4/QNX）→ 混合内核
- 微内核设计原则：最小化内核功能，服务移到用户态，消息传递通信；seL4 是首个完成形式化验证的内核

### 硬件抽象与异常

- ISA：CPU 向软件提供的接口，操作系统包含体系结构相关的汇编代码
- 用户态（EL0）/ 内核态（EL1）：svc 陷入、eret 返回
- 异常三类：陷阱（Trap，有意）、故障（Fault，可修复）、终止（Abort，不可恢复）
- 异常向量表：CPU 规定格式，基地址存 VBAR_EL1，16 项

### 进程与调度

- 进程 = 程序 + 上下文（PCB：PID/状态/寄存器/内存映射/文件描述符）
- 五状态模型：新建 → 就绪 → 运行 → 阻塞 → 终止
- 调度算法：FCFS / SJF / Round Robin / 多级反馈队列
- 上下文切换：保存当前进程状态 → 恢复下一进程状态

### 同步与互斥

- 临界区问题：互斥 / 进展 / 有限等待
- 硬件方案：Test-and-Set / Compare-and-Swap
- 信号量：P（wait）/ V（signal），生产者-消费者问题经典解法
- 死锁四条件：互斥 / 持有等待 / 不可抢占 / 循环等待

### 内存管理

- 分区 → 分段 → 分页 → 虚拟内存
- 页表：虚拟地址 → 物理地址映射，TLB 加速
- 页面置换：FIFO / LRU / Clock
- 缺页异常：访问不在物理内存的页面时触发

### 文件系统

- 文件描述符 → inode → 数据块
- 目录结构：树形目录，硬链接 vs 软链接
- 磁盘调度：FCFS / SSTF / SCAN / C-SCAN

## 课程特色

基于 ARM64 架构（AArch64），从硬件视角理解 OS：异常向量表、EL0/EL1 切换、svc/eret 指令、VBAR_EL1 寄存器。这与传统 x86 视角的 OS 课程有明显区别。
