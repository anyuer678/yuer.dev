## 项目介绍

软件交互课程大作业，一个校园 C2C 二手交易平台。面向学生用户，卖二手商品、按条件找商品、留言议价。项目按团队分工开发，每位成员负责一部分功能并写功能说明文档。

## 技术栈

Spring Boot 一键启动 + MyBatis + MySQL 5.7（JDK 1.8），前端 webapp/JSP 页面，Navicat 导入 c2c.sql 初始化数据。

## 功能模块

- **账号**：手机号 + 短信验证码注册登录、忘记密码、个人信息（姓名/性别/学号/宿舍号/邮箱/所在校区）
- **商品**：按分类/校区/成色多条件组合筛选、发布商品、我发布的商品、商品详情留言
- **检索**：站内搜索引擎、发布求购信息
- **扩展**：价格参考接口（同分类成交价 min/max/avg）、一键议价（少 5 元/少 10 元/包邮/自定义金额）、求购订阅表、消息系统（交易/价格提醒/过期提醒 + 已读标记）

## 踩过的坑

- JSP + 原生 JS 的交互层代码量大，筛选条件一多，查询 SQL 就要动态拼条件，注意防注入用参数绑定
- 短信验证码在演示环境没有真实短信服务，用固定验证码 + 日志输出兜底
- 求购订阅和议价是扩展需求，消息表要扩展类型枚举，旧数据兼容要考虑

## 我的收获

- 多条件组合筛选的 SQL 写法（动态 WHERE）是这次最实用的技能点
- 团队分工时"每人一个模块 + 功能说明文档"的模式，让每个人的贡献可追溯
- 交易类业务的状态（在售/已售/已下架）要用枚举管理，靠字符串裸写容易乱
