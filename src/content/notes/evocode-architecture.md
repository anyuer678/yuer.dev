## 背景

EvoCode 立项时，分析引擎和报告生成都在一个 Python 服务里。跑通原型很快，
但代码分析（确定性）和 LLM 输出（概率性）的演化节奏完全不同。

## 发生了什么

第一次拆分发生在引入多模型支持时：LLM 的 Provider 抽象被 Spring Boot 网关
接管，Python 侧只保留确定性分析。数据流变成单向：分析结果 → 网关 → LLM。

## 结论

确定性计算和概率性生成是两种"信任等级"，混在一起会让调试互相污染。
拆开后：分析结果可单测、可缓存；LLM 生成可以随时换模型而不影响事实层。
下一步计划：把分析任务异步化，支持增量解析。
