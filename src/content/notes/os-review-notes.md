## 基础概念

操作系统是管理计算机硬件与软件资源的系统软件，目标是方便、有效、可扩展、开放。四个基本特征：**并发、共享、虚拟、异步**。

- **并发 vs 并行**：并发是同一时间段内交替执行（单核即可），并行是同一时刻真正同时执行（需多核）
- **共享**：互斥共享（如打印机）与同时共享（如磁盘）
- **内核**：操作系统最核心部分，常驻内存
- **用户态 / 内核态**：特权指令只能在内核态执行，普通指令在用户态
- **系统调用**：用户程序请求内核服务的接口，是用户态进入内核态的主要方式

多道程序设计是并发的基础：内存中同时放多道程序，CPU 空闲时切换执行。

## 进程与线程

程序是静态实体（存于磁盘的指令序列），进程是程序的一次执行过程，是**资源分配的最小单位**；PCB（进程控制块）是进程存在的唯一标志。

进程三态：**就绪 → 运行 → 阻塞**。原语是不可中断的操作（如进程创建、终止、阻塞、唤醒）。上下文切换：CPU 从一个进程切换到另一个进程，保存旧进程现场、恢复新进程现场。

线程是**CPU 调度的最小单位**，同一进程的线程共享地址空间、代码、数据、文件。线程模型：

- 一对一（一个用户线程映射一个内核线程）
- 多对一（多个用户线程映射一个内核线程）
- 多对多

## CPU 调度

- **抢占式**：进程可能被更高优先级进程打断
- **非抢占式**：进程主动让出 CPU
- 调度指标：周转时间、带权周转时间（周转/服务时间）、响应时间、吞吐量

| 算法 | 特点 | 问题 |
|---|---|---|
| FCFS 先来先服务 | 简单公平 | 长作业可能阻塞后续短作业 |
| SJF 短作业优先 | **平均周转时间最小** | 需预知运行时间，可能饿死长作业 |
| 优先级 | 按优先级调度 | 低优先级可能饿死 |
| 时间片轮转 | 适合分时系统 | 时间片大小影响性能 |

## 内存管理与虚拟内存

程序装入方式：绝对装入、可重定位装入、动态装入。地址重定位把逻辑地址转换为物理地址。

连续分配：单一连续、固定分区、动态分区。分区分配算法：

- **首次适应**：从头找第一个够大的空闲区
- **最佳适应**：找最小的够大空闲区（产生最多小碎片）
- **最坏适应**：找最大的空闲区（减少小碎片但大块被切碎）

**内部碎片**：分配给进程但没用上的内存（固定分区产生）；**外部碎片**：空闲区太小无法利用（动态分区产生）。

覆盖与交换是早期扩充内存的手段。

- **分页**：把逻辑地址空间分成大小相等的页，物理内存分成页框，页表记录映射关系，**消除外部碎片**；快表（TLB）加速地址变换
- **分段**：按程序逻辑结构划分，段长可变，便于共享和保护
- 分页与分段的结合：段页式

虚拟内存的基础是**局部性原理**（时间局部性 + 空间局部性）：程序在一段时间内只访问部分地址。请求分页在缺页时才把页面调入内存，产生**缺页中断**。

页面置换算法：FIFO、LRU（最近最久未使用）、OPT（最优，理论）、LFU、Clock（时钟）与改进型 Clock。**FIFO 可能出现 Belady 异常**（分配页框增多缺页反而增加），LRU 和 OPT 不会。

抖动：页面频繁换入换出，CPU 利用率骤降。工作集模型用于防止抖动。

## 死锁

死锁必要条件（缺一不可）：

1. **互斥**：资源一次只能被一个进程使用
2. **请求并保持**：进程占着资源又请求新资源
3. **不可剥夺**：资源不能被强行抢走
4. **循环等待**：进程间形成资源等待环

处理策略：

- **预防**：破坏四个必要条件之一（如资源一次性分配、按序申请资源）
- **避免**：**银行家算法**，每次分配前判断是否处于安全状态
- **检测**：资源分配图，有环且环中资源可再分配则可能死锁
- **解除**：撤销进程、剥夺资源

## 文件系统

文件是信息的逻辑单位，目录是文件名到 FCB（文件控制块）的映射。

- 逻辑结构：顺序文件、索引文件
- 物理结构：连续分配、链接分配、索引分配
- 空闲空间管理：位示图、空闲链表
- 文件共享：硬链接（同一 inode）、软链接（符号链接）
- 文件保护：访问控制矩阵、口令、加密

## I/O

I/O 系统由设备、设备控制器、驱动程序组成。

- **中断**：设备完成任务后发中断，提高 CPU 与 I/O 的并行性；中断向量指向中断处理程序
- **DMA**：直接内存访问，批量传输数据，减少 CPU 干预
- **缓冲**：缓解 CPU 与设备速度不匹配，如双缓冲、循环缓冲
- **设备独立性**：应用程序与具体物理设备解耦，通过逻辑设备名访问

## 一句话记忆

> 进程是资源分配单位、线程是调度单位；分页管空间、虚拟内存靠局部性；死锁四条件、预防靠破坏；文件系统以 FCB 为索引。
