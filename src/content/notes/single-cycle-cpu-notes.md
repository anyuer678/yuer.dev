## 实验目标

设计一个**单周期 ARM 微处理器**：单个时钟周期内完成取指、译码、执行、访存、写回五个阶段。工具链：SystemVerilog（RTL）+ Digital（电路观测）+ GNU 工具链（汇编反汇编）+ Vivado（仿真）。

## 指令系统（三类指令）

### 数据处理指令

格式：`INSTR[cond][S] rd, rn, #immediate` 或 `INSTR[cond][S] rd, rn, rm`（方括号为语法记号）

- op = 00；`[25]` = 1 立即数 / 0 寄存器
- 算术逻辑：ADD(0100) / SUB(0010) / AND(0000) / ORR(1100)
- `[20]` = S（置位则更新 CPSR 状态标志）

### 访存指令

- `LDR rd, [rn, #offset]`：rd ← Mem[rn+offset]
- `STR rd, [rn, #offset]`：Mem[rn+offset] ← rd
- op = 01；`[20]` = L（1 读 0 写）；imm12 零扩展

### 分支指令

- `B target`：PC ← PC + 8 + imm24 << 2
- 注意：**PC 指向当前指令地址 + 8**（流水线取指已多取两条）；ARM 无延迟槽

## 条件码

cond 字段（指令位 `[31:28]`）决定指令是否执行：

| cond | 含义 | 条件 |
|---|---|---|
| 0000 | EQ | Z=1 |
| 0001 | NE | Z=0 |
| 0100 | MI | N=1 |
| 0101 | PL | N=0 |
| 0110 | VS | V=1 |
| 1010 | GE | N=V |
| 1011 | LT | N≠V |
| 1100 | GT | N=V 且 Z=0 |
| 1110 | AL | 无条件 |

## 处理器结构

自顶向下模块化：**程序计数器、寄存器文件、ALU、控制单元、指令存储器、数据存储器**。

- 控制单元：组合逻辑产生控制信号
- 数据通路：完成运算、传输、存储
- R15 读出值 = PC+8（与 ARM 语义一致）

## 验证方法：汇编 → 机器码 → 仿真

测试程序用 ARM 汇编写，例如：

```asm
SUB R0, R15, R15      ; R0 = 0
ADD R2, R0, #5        ; R2 = 5
ADD R3, R0, #12       ; R3 = 12
SUB R7, R3, #9        ; R7 = 3
ORR R4, R7, R2        ; R4 = 3 OR 5 = 7
SUBS R8, R5, R7       ; 置标志
BGE AROUND            ; 条件分支应跳转
AROUND: SUB R7, R7, R2
STR R7, [R3, #84]     ; mem[96] = 7
END_0: STR R2, [R0, #100] ; mem[100] = 7
```

流程：GNU 工具链汇编+反汇编得标准机器码 → 写入 memfile.dat → Vivado 加载仿真 → 观测寄存器/内存/分支跳转，与标准 ARM 执行结果对比。

## 遇到的问题

- **GNU 工具链中文路径报错**：文件路径含中文（中文用户名导致）终端无法识别 → 迁移到纯英文路径
- **Vivado 工程中文路径故障**：工程打不开、波形加载失败、存储器文件读不到 → 重建纯英文路径工程
- **仿真文件加载异常**：memfile.dat 位置错误导致指令存储器空 → 调整路径匹配工程读取目录

## 收获与思考

- 单周期设计的代价：**时钟周期必须足够长**以容纳最慢指令（访存），所以后期会引入流水线提高吞吐
- 条件执行（cond 字段）是 ARM 特色：一条指令即可实现条件跳转逻辑，减少分支开销
- 验证要分层：指令级（汇编对比）→ 电路级（Digital 观测）→ 仿真级（Vivado 波形）
- 硬件工程的路径规范意识：工具链对路径要求苛刻，规范操作能省大量调试时间
