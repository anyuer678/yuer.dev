## 进度管理

**关键路径法（CPM）：**
- 关键路径：最长路径，决定项目最短工期
- 总浮动 = LS - ES = LF - EF
- 自由浮动 = 后继ES - 本EF

| 知识点 | 公式 |
|--------|------|
| 最早开始 | ES = max(前驱EF) |
| 最早完成 | EF = ES + 工期 |
| 最晚完成 | LF = min(后继LS) |
| 最晚开始 | LS = LF - 工期 |

## 成本管理（挣值分析）

| 指标 | 含义 | 公式 |
|------|------|------|
| PV | 计划值 | 计划完成工作预算 |
| EV | 挣值 | 已完成工作预算 |
| AC | 实际成本 | 已完成工作实际成本 |
| CV | 成本偏差 | EV - AC（正=节约） |
| SV | 进度偏差 | EV - PV（正=提前） |
| CPI | 成本绩效指数 | EV / AC（>1=节约） |
| SPI | 进度绩效指数 | EV / PV（>1=提前） |

**挣值分析口诀：**
- 偏差 = 挣值 - 对比值（正=好，负=差）
- 指数 = 挣值 / 对比值（>1=好，<1=差）

## 风险管理

| 应对策略 | 适用场景 | 说明 |
|----------|----------|------|
| 规避 | 负面风险 | 消除威胁 |
| 转移 | 负面风险 | 转给第三方（保险、外包） |
| 减轻 | 负面风险 | 降低概率或影响 |
| 接受 | 负面风险 | 主动/被动接受 |
| 开拓 | 正面风险 | 确保机会发生 |
| 分享 | 正面风险 | 与第三方共享 |
| 提高 | 正面风险 | 增加概率或影响 |
