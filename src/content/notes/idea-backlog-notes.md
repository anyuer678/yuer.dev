## 背景

平时刷到好用的 CLI、插件或 AI 工具时，常会冒出"这个我也能做"的念头。攒得多了，就整理成一份想法清单：先放开列，再按类别归档，最后用调研来筛哪些值得动手。

## 想法清单（82 条，分八类）

- **命令行小工具**（20 条）：Commit 消息生成器、代码 review 摘要器、Markdown → 思维导图、日志分析器、正则解释器、JSON 结构总结器、README 生成器、终端 AI 助手、剪贴板增强、时间戳模糊查询等。
- **浏览器插件**（10 条）：AI Slop 检测、网页摘要、翻译覆盖层、表单自动填写、文章转语音、反钓鱼预检、标签页整理、仓库"值不值得看"评分等。
- **MCP Server**（10 条）：个人笔记记忆、待办/习惯追踪、天气/交通查询、本地文件组织、RSS 摘要、书签管理、相册整理、键盘宏等。
- **本地 AI 工具**（10 条）：会议转写摘要（Whisper 封装）、语音指令控制台、图片批量重命名/分类、本地 OCR、PDF 问答、小仓库 RAG、字幕生成翻译、AI 壁纸生成器等。
- **个人效率/生活**（10 条）：智能记账分类、订阅到期提醒、购物比价、菜谱推荐、行程规划、邮件自动分类、密码管理器增强、断舍离助手等。
- **数据/格式转换**（10 条）：任意格式互转工具站、SQL 自然语言转换、代码翻译（Python↔JS）、旧代码升级、图片→HTML、流程图→Mermaid、长文简化等。
- **GitHub 生态**（5 条）：趋势周报生成、issue 关闭分类器、仓库健康度打分、Star 清理建议、许可证速查 CLI。
- **学习/教学**（7 条）：错题本分析、语言学习伴侣、读书笔记提炼、面试题生成、代码教学器、试卷生成器、论文摘要生成。

## 竞争现状调研（2026.07-08）

想法太多，逐个做不现实。于是对 100+ 方向做了一轮竞争现状调研：多组代理并行，web_search + GitHub API + HN 多源交叉验证，按**红海 / 有窗口 / 空白**三级评级。

几条典型结论：

- **红海**：Commit 消息生成（aicommits 7.8K★ + IDE 内置）、会议纪要（Otter/Fireflies + 腾讯会议内置）、README 生成（readme-ai 数万星）、PDF 表格提取（Adobe 官方 + 5+ SaaS）、终端 AI 助手（Warp/Copilot CLI 重仓）。
- **有窗口**：JSON 结构总结（中文几乎空白）、周报生成（全是 CLI 糙工具、无独立产品）。
- **空白**：日志时间戳模糊查询——四组中英搜索零独立工具，只剩云平台内置和一篇学术论文，需求却被大量 "grep 教程" 反向验证。

## 筛选结果：7 个雏形

按"低责任、可快速出品、能解决自己真实问题"的标准，从清单里挑了 7 个落地成雏形：

| 雏形 | 对应想法 |
|---|---|
| 日志时间戳模糊查询器 | 空白方向，直接验证需求 |
| 语音指令控制台 MCP | 本地 AI × MCP 交叉 |
| 图片批量 AI 重命名器 | 本地 AI 图片处理 |
| Star 清理建议器 | GitHub 生态 |
| 中文代码教学器 | 学习/教学 |
| API 密钥保险箱 | 解决自己的密钥管理痛点 |
| 旧代码升级器 | 数据/格式转换 |

## 现在的状态

82 条想法里做了 7 个（均为雏形，未完成），其余保留在清单里。这个流程本身也沉淀成了习惯：**想法先攒，调研再筛，动手只做能解决自己问题的**。
