## 背景

暑期实训（2 周），团队协作开发一个在线教育平台。模拟真实教育场景：教师发布课程和作业，学生选课学习、提交作业、参加考试。

## 技术栈

- **后端**：Java + Spring Boot + MyBatis
- **前端**：Vue.js + Element UI
- **数据库**：MySQL
- **部署**：Tomcat

## 核心功能

1. **用户管理**：教师 / 学生角色，注册登录
2. **课程管理**：教师创建课程、发布课件和视频
3. **选课系统**：学生浏览课程、选课退课
4. **在线学习**：课件浏览、视频播放、学习进度追踪
5. **作业系统**：教师发布作业、学生提交、教师批改
6. **考试测评**：题库管理、在线考试、自动评分
7. **互动讨论**：课程论坛、师生问答
