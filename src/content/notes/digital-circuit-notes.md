## 第1章 逻辑代数基础

| 知识点 | 核心 |
|--------|------|
| 基本运算 | 与(AND)、或(OR)、非(NOT) |
| 常用公式 | A+AB=A, A(A+B)=A, A+Ā=1, A·Ā=0 |
| 德摩根定律 | `(AB)'=A'+B'`, `(A+B)'=A'B'` |
| 对偶规则 | 将·换成+，+换成·，0换成1，1换成0 |
| 最小项 | n个变量的乘积项，包含所有变量，`m₀~m₂ⁿ-₁` |
| 最大项 | n个变量的和项，包含所有变量，`M₀~M₂ⁿ-₁` |

**卡诺图化简步骤：**
1. 画卡诺图，填入1和0（无关项填×）
2. 圈最大的矩形（2ⁿ个1）
3. 圈数越少越好，圈越大越好
4. 每个圈至少包含一个新的1
5. 写出最简与或式

## 第2章 组合逻辑电路

| 电路 | 功能 | 表达式 |
|------|------|--------|
| 半加器 | 1位二进制加法 | S=A⊕B, C=A·B |
| 全加器 | 含进位的加法 | S=A⊕B⊕Cᵢ, Cₒ=AB+(A⊕B)Cᵢ |
| 编码器 | 2ⁿ→n位编码 | 优先编码器74148 |
| 译码器 | n→2ⁿ位 | 74138（3-8译码器） |
| 数据选择器 | n位选择1位输出 | MUX，2ⁿ选1 |
| 加法器 | 并行加法 | 超前进位加法器 |

**竞争冒险：**
- 原因：信号经不同路径到达同一门，产生毛刺
- 消费：增加冗余项、加滤波电容、引入选通脉冲

## 第3章 触发器

| 触发器 | 触发方式 | 特征方程 |
|--------|----------|----------|
| RS | 电平 | Q* = S + R'Q, SR=0 |
| JK | 边沿 | Q* = JQ' + K'Q |
| D | 边沿 | Q* = D |
| T | 边沿 | Q* = TQ' + T'Q = T⊕Q |
| T' | 边沿 | Q* = Q'（翻转） |

**触发器对比表：**

| 类型 | 输入 | 功能 | 用途 |
|------|------|------|------|
| RS | S,R | 置1/置0/保持 | 基本锁存 |
| D | D | 跟随D | 数据寄存、移位 |
| JK | J,K | 保持/置0/置1/翻转 | 通用触发器 |
| T | T | 保持/翻转 | 计数器 |

## 第4章 时序逻辑电路

| 知识点 | 核心 |
|--------|------|
| 分析步骤 | 写方程→列状态表→画状态图→画时序图 |
| 计数器 | 同步/异步，二进制/十进制/任意进制 |
| 寄存器 | 存储n位二进制数据 |
| 移位寄存器 | 数据逐位移动 |
| 同步 vs 异步 | 同步：同时触发，速度快；异步：逐级触发，速度慢 |

**任意进制计数器：**
- N < M：用反馈清零法或反馈置数法
- N = M：直接用现成计数器级联

| 编号 | A | vs | B | 一句话 |
