## 第1章 算法基础

| 知识点 | 核心 |
|--------|------|
| 算法特性 | 有穷性、确定性、可行性、输入、输出 |
| 时间复杂度 | `O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)` |
| 递推方程 | T(n) = aT(n/b) + f(n) |
| 主定理 | `T(n) = aT(n/b) + O(nᵈ)`：d<logba→O(n^logba)；d=logba→O(nᵈlogn)；d>logba→O(nᵈ) |

## 第2章 分治法

| 知识点 | 核心 |
|--------|------|
| 基本思想 | 分解→求解→合并 |
| 归并排序 | O(n log n)，稳定 |
| 快速排序 | O(n log n)平均，不稳定 |
| 二分查找 | O(log n) |
| 大整数乘法 | Karatsuba算法 O(n^1.585) |
| Strassen矩阵乘法 | O(n^2.807) |
| 最近点对 | O(n log n) |

## 第3章 动态规划

| 知识点 | 核心 |
|--------|------|
| 基本思想 | 最优子结构 + 重叠子问题 |
| 与分治区别 | 分治子问题独立，DP子问题重叠 |
| 背包问题 | 0-1背包：dp[i][w] = max(dp[i-1][w], dp[i-1][w-wᵢ]+vᵢ) |
| 矩阵链乘法 | m[i][j] = min{m[i][k]+m[k+1][j]+pᵢ₋₁pₖpⱼ} |
| 最长公共子序列 | LCS(i,j) = LCS(i-1,j-1)+1 (若xᵢ=yⱼ) |
| 最长递增子序列 | LIS，O(n log n) |
| 编辑距离 | dp[i][j] = min(删除, 插入, 替换) |

**DP解题步骤：**
1. 定义状态（子问题）
2. 写状态转移方程
3. 确定初始条件和边界
4. 确定计算顺序
5. 得出最优解

## 第4章 贪心算法

| 知识点 | 核心 |
|--------|------|
| 基本思想 | 每步取局部最优 → 全局最优 |
| 与DP区别 | 贪心不回溯，DP考虑所有子问题 |
| 活动选择 | 按结束时间排序，选不冲突的 |
| 分数背包 | 按性价比排序，O(n log n) |
| Huffman编码 | 按频率建最优前缀码 |
| Dijkstra | 单源最短路径，O(n²)或O((n+m)logn) |
| Prim/Kruskal | 最小生成树 |

---

## 第5章 回溯法

| 知识点 | 核心 |
|--------|------|
| 基本思想 | 深度优先搜索 + 剪枝 |
| 解空间 | 子集树、排列树、n叉树 |
| 剪枝函数 | 约束函数 + 限界函数 |
| N皇后 | 排列树，O(n!) |
| 0-1背包 | 子集树，O(2ⁿ) |
| 图着色 | 子集树，O(nᵐ) |
| TSP | 排列树，O(n!) |

---

## 第6章 分支限界法

| 知识点 | 核心 |
|--------|------|
| 基本思想 | 广度优先/最优优先 + 限界函数 |
| 与回溯区别 | 回溯求所有解，分支限界求最优解 |
| FIFO分支限界 | 队列式 |
| LC分支限界 | 最小耗费优先 |

---

## 回溯法 vs 分支限界法对比

| 比较项 | 回溯法 | 分支限界法 |
|--------|--------|------------|
| 搜索方式 | DFS | BFS/最优优先 |
| 目标 | 所有可行解 | 最优解 |
| 数据结构 | 栈 | 队列/优先队列 |
| 剪枝 | 约束函数 | 限界函数 |

---

## 核心对比速查表

| 编号 | A | vs | B | 一句话 |
|------|---|----|---|--------|
| 1 | 分治 | DP | 子问题独立 vs 子问题重叠 |
| 2 | DP | 贪心 | 考虑所有子问题 vs 每步局部最优 |
| 3 | 回溯 | 分支限界 | DFS求所有解 vs BFS求最优解 |
| 4 | 0-1背包 | 分数背包 | DP/回溯 O(2ⁿ) vs 贪心 O(n log n) |
