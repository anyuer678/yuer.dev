## 背景

想有个随时可用的 Linux 环境练手，也能挂个人服务。机器是闲鱼买的**成品 N100 迷你小主机**（不是自己组装的），N100 是 Intel 的低功耗处理器，整机功耗低、体积小，适合 7×24 当家庭服务器。到手直接装系统就能用，不用折腾硬件。

## 过程

1. **装系统**：Debian 最小安装，不带桌面，只装服务器需要的组件
2. **Docker 化部署**：所有服务走容器，数据挂卷，备份只需打包目录；重装系统后恢复服务只需把容器跑起来
3. **内网穿透**：家庭宽带没有公网 IP，用 frp 把内网 HTTP 端口映射到有公网的服务器，实现公网访问
4. **监控**：Uptime Kuma 做探活监控，服务挂了能收到通知

## 结论

容器化 + 数据挂卷是这台机器最高性价比的运维方式：系统出问题重装，服务数据还在，重启容器即恢复。这台机器目前主要用来跑个人小服务、当开发练手环境。
