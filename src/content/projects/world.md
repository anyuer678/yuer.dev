## 项目介绍

做算法题的时候，很多结论只能"感觉对"。排队系统加一台服务器到底快多少、缓存换 LRU 能救回多少命中率、谢林模型里多小的偏好会撕裂成完全隔离——这些都能算，但零散写脚本既不复现也难比较。

WorldLab 把这些收敛成一条固定流程：**定义模型 → 运行真实模拟 → 观察状态 → 管理实验 → 比较结果**。模型用版本化 Schema 声明，引擎统一，实验可回放、可批量、可导出。

## 设计目标

- 一条链路到底：模型 → 运行 → 实验 → 报告，中间不靠手写脚本拼接
- 结果可信：每个模型有参数校验、确定性测试、边界测试与示例 spec
- 可比较：批量实验给出统计量与自动发现，而不是一行平均分
- 可扩展：模型可作插件载入，不改核心代码
- 中文界面：模型名、参数标签、场景描述全部中文化，不做半截翻译

## 功能

- 九个内置模型：排队系统、CPU 调度、缓存模拟、元胞自动机、谢林隔离、SIR 传染病、捕食者-猎物、交通路网、沙堆
- 工作台：模型选择 → 结构化参数面板（由 `params_schema` 生成）→ 运行/暂停/单步/重置/检查点 → 实时视图 → 事件日志
- 一键场景：每个模型内置 2–3 个中文场景，点卡片即建会话、连续运行并出结果
- 实验管理：历史会话、结果对比、批量实验、95% 置信区间、自动发现显著差异
- 报告导出：Markdown / JSON / CSV（12 列 + BOM，Excel 直接打开不乱码）
- 插件式模型库：`WORLDLAB_PLUGIN_MODULES` 声明模块名即可挂载自定义模型，插件也能声明场景

## 架构

```text
浏览器（Vite + TypeScript 前端）
   │  /api 反代
nginx ──→ FastAPI + uvicorn（backend）
             ├── 模拟引擎：时间步进 + 离散事件，检查点/恢复/取消
             ├── Schema 层：版本化模型定义 + 迁移 + 校验
             ├── 实验层：会话、批量、统计（置信区间 / 自动发现）、报告
             └── SQLite（WAL，数据落命名卷）
```

前端按模型拆 visualizer 声明与适配器：队列看等待曲线、CPU 调度看甘特、元胞与沙堆看网格着色、交通看路段占用。**渲染只读模拟状态，不参与计算**，所以同一份结果在单步、暂停、重放三种情况下看到的一致。

## 技术选择

- **Python + FastAPI**：模型作者写的是数值逻辑，Python 生态在这块最顺；pydantic 直接把 Schema 校验和 API 契约并成一套
- **自研轻量引擎而非现成仿真库**：SimPy 之类把调度藏得较深，检查点/取消/资源上限这些边界反而更难落实
- **SQLite（WAL）**：模拟会话是短生命周期、写多读少，单文件库比引入 Postgres 省事，命名卷挂载即持久化
- **前端 Vite + TypeScript**：视图与引擎解耦后，前端只需按 `params_schema` 和引擎输出做适配
- **Docker Compose 双服务**：`api` 带 healthcheck、`web` 用 nginx 托管构建产物并反代 `/api`，依赖全部锁版本

## 开发过程

按阶段 0–6 推进，每轮都留改进记录与取舍说明（`CHANGELOG.md` / `DECISIONS.md` / `TESTING.md`），所以"这轮修了什么真问题"是可查的，不是凭记忆。

测试口径写在 README 里并进 CI：后端 `uv sync --frozen` + `pytest`，前端 `npm ci` + `vitest` + `tsc -b && vite build`。首次接入 CI 就是后端 270 项、前端 60 项全绿。
