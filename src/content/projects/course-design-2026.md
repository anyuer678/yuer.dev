## 项目介绍

课程设计最容易变成"交完就忘"。这个仓库把 38 项课程任务组织成一张学习地图，并且只保留**能跑、能解释、能复现**的部分作为代表作品——不是把实验报告堆在一起，而是把课上的技术点写成真产品。

九件产品全部零第三方依赖：纯 Python 标准库 + 自研地基，引擎层直接 import 六个课程项目的真实实现，不重写。

## 设计目标

- 每一件产品都能 30 秒讲清楚：做了什么、为什么有用、哪里最难
- 零依赖作为纪律：不装 Flask、不装 Redis、不装 MQTT broker、不用前端框架
- 数字要能对账：报告里的每个计数都来自实际数据库，过期即红
- 技术验收（能跑、通过测试）与学习验收（能解释、能改）分开记录，不混为一谈

## 功能

- **Studio**（:8017）：作品集门户，产品目录、一键启停、TCP 探活状态面板——"在线 = 端口连得上"
- **CourseLab**（:8024）：把 33 个课程项目升格成能登录、能在线做实验、能布置任务与评测的教学平台
- **LinkBox**（:8018）：自托管工具站，短链 / 带口令与过期的文本暂存 / 文件互传 / 二维码
- **DataScope**（:8020）：CSV 自助分析，列画像 → 配方清洗 → Apriori/K-means 挖掘 → 每步计数可对账的报告
- **SimLab**（:8019）：算法仿真回放，每一帧都是真实引擎现算，改参数即改即算
- **CacheKV**（:8021）：自托管键值缓存，TTL、原子快照持久化、命中率统计页
- **SensorHub**（:8022）：传感器 → 手写 MQTT broker → SQLite → WebSocket 实时曲线 → 阈值告警
- **BoardWeb**（:8025）：浏览器画板，图形库、选择微调、贴图、实时协同、撤销重做 + 轮转备份
- **Board**（:8023）：Java Swing 桌面画板，7106 项自动检查（含离屏像素对快照影子模型）

## 架构

```text
浏览器 / 手机（原生 HTML/JS + 本地化 ECharts，无前端框架）
   │  HTTP · WebSocket（RFC 6455 服务器侧手写：握手/帧/掩码/ping-pong）
┌──┴─────────────────────────────────────────────┐
│  webframe 微框架 + netlab 单线程事件循环         │ ← 自研地基，8 个 Web 产品同底座
├────────────────────────────────────────────────┤
│  产品层  studio · courselab · linkbox · datascope│
│          simlab · cachekv · sensorhub · boardweb│
├────────────────────────────────────────────────┤
│  引擎层  B11 netlab · B12 算法 · B26 挖掘        │
│          B31 短链 · B35 MQTT · B38 mini-redis   │ ← 复用课程项目真实实现，零重写
├────────────────────────────────────────────────┤
│  存储    SQLite / 快照文件 / 轮转备份（可审计）  │
└────────────────────────────────────────────────┘
```

## 技术选择

- **自研 webframe 而不是 Flask**：路由、模板、静态资源加起来不到千行，但能同时讲清楚 HTTP 解析、WebSocket 握手、长连接回收——用框架就只剩调用
- **单线程事件循环（netlab）**：八个产品共用一个底座，行为可预期；并发问题在课设规模下不值得引入线程池
- **手写 RFC 6455 / MQTT 3.1.1 / QR 编码器**：这几个是课程主线（计网、物联网），借第三方库就等于跳过考点
- **SQLite 单文件**：每个产品一个库，备份就是拷文件；审计日志与轮转备份保证可回滚
- **Docker 一镜像多入口**：`python:3.12-slim` + 标准库，构建期零 pip install，端口与产品矩阵 1:1

## 开发过程

先做地基（webframe、事件循环），再让产品按"能独立演示"的粒度逐个落地。每个产品配套 pytest 用例，产品矩阵合计 291+ 项、CourseLab 自检 154 项，桌面画板另有 7106 项检查——双入口（pytest 与 `run.bat`）都能跑绿。

诚实登记边界：Studio 状态面板探活写死 `127.0.0.1`，容器模式下兄弟产品显示离线是预期；CourseLab 的在线实验运行器依赖本机 Windows shell，容器内课程内容完整但跑实验要用本机模式。
